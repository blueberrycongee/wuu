# Conversation corpus

Twelve locally reviewed, sanitized conversation excerpts. Keep this directory
portable: it contains no raw session IDs, source database, replacement map,
credentials, original tool payloads or attachments.

Run and admission instructions: [development guide](../../../../docs/en/project/development.md#conversation-corpus-acceptance)
([中文](../../../../docs/zh-cn/project/development.md#真实会话样本验收)).

The recorded model names are provenance labels, not model quality comparisons.
Text is historical test content and may contain incorrect technical claims.
Tool counts and reply order are retained; tools read synthetic fixture content.
Streaming segmentation and timing are simulated.
