# Workspace files empty state

From `desktop`, run `npx vite --host 127.0.0.1 --port 5189`, then open
`http://127.0.0.1:5189/dev/workspace-empty/`.

The fixture mounts the production file tree and `WorkspacePanelEmpty` against a
synthetic empty project. It reads no local files. Use `?theme=dark` for the dark
variant and `?font=20` for large text.
