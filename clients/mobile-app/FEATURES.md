# 手机功能与桌面对应

手机加载仓库内的完整共享 renderer，所有会话 RPC 发送给选中的电脑。界面和状态逻辑来自 `desktop/src/renderer`，远程适配位于 `clients/mobile-web/src/lib/desktopBridge.ts`。以下对应关系以当前桌面行为为基准。

| 能力 | 手机交互与执行位置 |
| --- | --- |
| 账号、电脑目录、丢失设备 | 在设备页注册、登录、改密、恢复和移除设备；选择在线电脑，顶部返回设备列表。离线电脑明确显示离线。 |
| 会话创建、历史、搜索、归档、组织 | 共享会话状态与导航；手机抽屉承载列表，打开会话后使用全屏内容区。历史按页读取，图片按需加载。 |
| 模型、参数、运行环境 | 共享输入框菜单，设置修改对应电脑上的配置。模型凭据与执行留在电脑。 |
| 流式输出、工具、队列、停止、交互问答 | 共享运行事件、工具展示和问题表单，通过加密连接执行真实请求；电脑可以同时继续相同会话。 |
| 项目与工作区 | 手机文件夹选择器浏览电脑目录，支持输入绝对路径、创建目录、添加、迁移和移除项目。输入框的项目菜单选择新会话执行位置。 |
| 文件浏览、代码与差异预览 | 在“产物与工具”中全屏打开文件；当前桌面文件浏览本身也是只读。可将完整文件分块下载后交给系统分享或保存，单文件上限 64 MB。 |
| 图片与 PDF 附件 | 使用系统照片/文件选择器；预览使用共享组件，图片可交给系统分享。模型是否支持图像由所选模型决定。 |
| Git 审查、分支、提交 | 使用电脑上的 Git 服务与共享审查页；手机将面板展开成独立页面，返回按钮回到工具列表或会话。 |
| 终端 | 在电脑创建真实 PTY；手机用顶部标签切换终端，触屏按键补充 Ctrl、Esc、Tab、方向键等软键盘缺少的操作。Android 后台同步服务运行时保留连接；无法续接的终端明确提示重新打开。 |
| 扩展、技能和扩展界面 | 复用公开 Extension API、电脑安装与信任状态；在电脑目录中选择扩展目录或 ZIP 安装。界面资源经加密传输、内容摘要验证并绑定连接代际。停用、配置与卸载调用电脑实现。 |
| 外部链接与导出 | HTTP(S) 链接打开系统浏览器；文件交给系统分享目标。电脑 Finder/reveal/context menu 对应手机文件预览和导出，不伪造电脑系统菜单。 |
| 窗口与导航 | 手机使用抽屉、全屏工具页和系统返回，代替桌面弹出独立窗口。返回优先关闭弹层、设置、抽屉及工具页，再返回电脑列表。 |
| 语音输入 | 使用 iOS/Android 系统键盘的听写入口；桌面专用录音、隐私设置不在手机上假装成功。系统听写权限由操作系统管理。 |
| 后台与网络恢复 | Android 连接电脑时启动前台服务并显示同步通知，进入后台继续接收消息；断开、返回电脑列表或划掉 App 时停止。服务不可用及 iOS 后台时暂停传输，返回前台恢复；重连等待消息回放后才恢复就绪状态。系统推送可使用部署者自己的 APNs/FCM，见部署文档。 |
| 桌面专用宿主设置 | 远程宿主开关、旧 QR 配对、桌面宠物、桌面窗口及本机构建信息属于对应宿主能力；手机版账号入口负责账号与设备管理。不可用的宿主操作返回明确错误。 |

横竖屏均使用手机导航模式，安全区保护刘海和手势区域。软键盘变化通过实际可视区域同步布局；横屏极短视口在输入时收起电脑栏，保留输入行与 44px 操作目标。长文本输入保留滚动，不用缩放整页替代布局。

账号服务器受信任，电脑是会话权威来源。手机没有云端执行、自动唤醒或服务器会话副本。系统分享后的外部副本由用户管理；App 私有导出缓存的清理规则见 [构建和使用说明](README.md)。
