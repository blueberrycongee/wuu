让内容形成清楚的阅读节奏

可以先建立一条稳定的阅读主线：用户提出问题，过程摘要交代进展，回答承载结论与解释。阅读时，目光能顺着同一条左侧边界往下走。

长回答需要兼顾连续阅读和快速定位。正文保持均匀的行距，段落之间留出适度空白；进入新的章节时，再通过标题和更大的间距提醒读者。

字号、间距与缩进一起调整

每种距离都应表达清楚的内容关系：

  • 正文段落承担连续叙述，同一主题的内容自然衔接。
  • 列表条目方便比较；文字换行后，继续对齐条目的第一行。
    • 补充说明只进入下一层，保持可预测的缩进。
  • 代码与表格使用独立容器，外边缘仍落在正文主线上。
标题靠近它解释的下文，章节之间保留明显的停顿。

把阅读规则集中管理

在 conversation-shell.css 中定义语义变量，让各类消息使用同一套基础尺度。

CSS · 规则示意
.answer {
  font-size: var(--reading-size);
  line-height: var(--reading-leading);
}

短回答也需要加标题吗？

短回答直接开始正文就可以。标题只在内容需要分节时出现，让每一层视觉强调都有明确的用途。
