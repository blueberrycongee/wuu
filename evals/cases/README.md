# Public eval cases

Put reusable, redistributable evaluation inputs here. Each case should have its
own directory containing a short README, the exact prompt, fixture provenance
and license, setup steps, timeout, and deterministic grading instructions.

Do not copy private repositories or third-party benchmark data without a
license that permits redistribution. A result may instead point to an external
public benchmark and immutable upstream commit when its data should not be
vendored.
