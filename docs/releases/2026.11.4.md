## Compatibility and migration

No manual migration is required. Existing model selections and explicit connection settings are preserved; retained model metadata does not guarantee continued availability from the provider. The new file APIs and plugin-family metadata are optional additions to the existing Extension API. Extensions using file saving or observation must check the host's advertised capabilities.
