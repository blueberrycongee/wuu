## Highlights

- The desktop now enforces a single instance, so launching the app again focuses the existing window instead of starting duplicate app-servers.
- In-app reduced motion is honored across the shell and motion primitives are deduplicated; the settings page no longer flickers on navigation.
- Window skin and icon artwork recover automatically after transient and evicted-asset failures, and bundled paintings now ship compressed at up to 1.5MP webp.
- Engine and model discovery is faster and more accurate: the advertised model catalog publishes without per-model probing, engine describe and model discovery get separate budgets, and per-model capabilities are learned from live sessions.

## Compatibility and migration

- The Design Mode bundled plugin is no longer included in packaged release builds while it remains under development; source builds keep it available. Installations that used Design Mode lose access to it until it ships again — no data migration is required.
