## Compatibility and migration

- The bundled Account Connectors are removed: every MCP server, standalone, project, or plugin-owned, now uses the same server model. Enabled connectors migrate automatically to standalone servers, but MCP OAuth sign-ins may need to be completed again. The plugin SDK and public protocol no longer expose connector identity APIs.
