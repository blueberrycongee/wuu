## Highlights

- Side chat uses the main conversation's external engine in a separate read-only session. If the engine reports that it lacks read-only support before replying, Wuu can send the question and its context to the configured default Wuu model.
- New text and attachments added while a message is being sent stay in the draft after Wuu accepts the message.
- The runtime picker gives the reasoning-effort column and selected model more room, shows the resolved default effort, and labels the speed control.
- Streaming tool calls and conversation updates do less repeated work, and cancelled worker runs can finish without waiting for a subscriber to drain its event queue.
