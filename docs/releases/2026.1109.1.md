## Highlights

- New Design workspace tool: a live HTML canvas where you can edit elements directly, pin comments, and hand revisions to the agent, with an OpenDesign-style tab strip and loopback previews.
- New bundled shell skins: public-domain paintings with halftone defaults, available in appearance settings.
- Reading and chrome polish: stronger heading hierarchy in Markdown messages, a roomier sidebar leading inset, detached picture-in-picture cards kept in one stack, a stable composer layout when the tool rail hides, and truncated sidebar labels that fade instead of ellipsizing.
- Saving engine settings no longer stalls on model discovery — the update returns immediately and the model catalog refreshes in the background.
- Conversation reliability: MCP servers stay admitted after a plugin-referenced turn, ACP agents no longer accumulate duplicate host instructions every prompt, and external sessions skip a redundant configuration wait.
- Failure visibility: dispatched one-shot automations keep their runs reachable with errors shown, connection removal failures surface through the shared toast, and Codex connections can now be removed while keeping the shared sign-in.
