## Highlights

- The runtime picker is now a flat three-column panel: an engine rail, a searchable list of models grouped by provider, and an effort column, with speed as a footer control. External engines are selected in the same panel, and ⌘/Ctrl+1–9 picks a visible model.
- Steering now works with external engines that resume a native session: sending input during a running turn interrupts it and starts the new input as the next turn on the same session, keeping provider-side context.
- Collapsing and expanding the sidebar slides smoothly instead of re-laying out the whole window each frame, and opening Settings no longer flashes a loading placeholder.
- Detaching PiP cards to the desktop flies every card along an arc to its stack position instead of teleporting the first card and sliding the rest.
