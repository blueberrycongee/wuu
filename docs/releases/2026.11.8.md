## Highlights

- Open Settings in one click from the sidebar gear, and keep Settings a floating card above the workbench at every window width instead of collapsing into a full-window sheet on medium windows or zoomed pages; its scrim now shares the standard modal backdrop rather than a one-off blurred rule.
- Share the host Computer Use contract with external engines over ACP, so connected agents reuse canonical targets, recover from stale snapshots, and get actionable target-busy errors.
- Unblock the first send while engine discovery is still probing model catalogs: engine availability now publishes before native model probing, so a slow engine startup can no longer hold your first draft hostage.
- Persist external-engine turns as structured transcripts: ACP/OpenCode reasoning, tool calls, and results now reload as the same items shown live instead of one flattened text blob.
