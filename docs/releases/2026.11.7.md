## Compatibility and migration

- `composerPresentation.getTelemetry()` no longer returns `tokensPerSecond`, `source`, `sampledAt`, `inputTokens`, or `outputTokens`; the snapshot now carries `contextUsage` only. Extensions that displayed token speed should estimate it from raw host events, as `examples/plugins/token-speed` does. Hosts older than 2026.11.7 keep the removed fields.
