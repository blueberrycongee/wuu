# 显式展示产物

Wuu 内置工具 `present_artifact` 将已有文件作为交付物展示给用户，例如：

```json
{"path":"output/chart.svg"}
```

模型用代码生成用户请求的图片、图表或文档后，调用该工具。图片在回答附近独立显示完整比例的预览和文件名，点击放大；其他文件使用已有产物卡片。模型无需再重复输出 Markdown 图片。

“本轮修改文件”卡片继续负责代码变更，不从 diff、普通文件链接或文件读取记录推断交付物。展示产物不会修改源文件，也不会产生文件变更事件。

## 数据与边界

工具使用当前线程的文件读取边界和敏感路径检查。只接受本地普通文件，最大 256 MiB，不下载远程 URL。常用位图通过内容嗅探识别，SVG 检查 XML 根节点并只作为 `img` 展示，不向页面插入 SVG 源码。

文件通过现有托管产物存储保存为快照。返回的 `ToolResult.content` 携带 `wuu-artifact` URI、SHA-256、大小及展示位置，保留在线程历史中。后续修改或删除工作区源文件不影响之前的快照。同轮重复发布同名、同类型、同内容的产物只显示一次；不同版本仍分别保留。

展示与模型看图是不同动作：该工具不将图片字节发送给模型，也不能代替视觉检查。现有结构化图片工具结果继续使用同一展示组件。本次接入的是 Wuu 内置工具链，不改变外部 Codex 引擎的事件适配。

## 验证

`tool_present_artifact_test.go` 覆盖权限、敏感路径、符号链接、工作树和线程克隆。`artifact_publisher_test.go` 覆盖真实线程接线、快照与历史序列化、类型校验和失败路径。前端 `ArtifactOutputs.test.tsx` 与 `TurnView.test.tsx` 覆盖预览、去重、点击放大，以及产物与原 diff 卡片同时存在。
