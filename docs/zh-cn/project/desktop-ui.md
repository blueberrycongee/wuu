# 桌面 UI 维护

等价控件使用共享 renderer 组件和设计变量。
[贡献约束（英文）](../../../AGENTS.md#ui-design-and-visual-acceptance)规定了字体、
间距、无障碍和实际渲染验收要求。行为变化时同步预览与说明，不把分支改动日志当作
现行设计规范。

## 可复用预览

[桌面预览目录](../../../desktop/dev/)包含使用合成数据的开发入口，用于重复检查
真实组件及其状态，不是产品入口，也不代表发行版已通过验收。在 `desktop/` 运行
`npx vite --host 127.0.0.1`，使用 Vite 显示的端口打开相应 `/dev/` 路径。
[小球预览（英文）](../../../desktop/dev/mascot/README.md)使用 `npm run lab:mascot`；
隔离的新手引导窗口使用 `npm run dev:onboarding`。这些预览不需要真实账号凭据。

修改组件时同步维护预览。临时截图存入忽略的产物目录，不与夹具源码一起提交。
检查浅深色主题、默认和大字号、窄宽窗口、长空内容、滚动、菜单和键盘焦点。
组件测试不能代替实际渲染检查；报告应明确实际检查过的条件。

## 嵌套圆角

使用 [base.css](../../../desktop/src/renderer/styles/base.css) 中的圆角与菜单变量。
同心嵌套通常需要外圆角接近内圆角加内缩距离；有间距的内外层使用同一圆角并不会
自然同心。优先沿用紧凑菜单的现有组合，不增加组件专属常量。应检查实际渲染关系，
不能用公式代替视觉验收。

## 滚动边缘渐隐

[scroll-fade.css](../../../desktop/src/renderer/styles/scroll-fade.css)用于有限高度的
工具/推理检查区和导航列表，按需启用。属性放在原有的垂直滚动节点上：

```tsx
<div className="existing-scroll-region" data-scroll-fade="compact" ref={scrollRef}>
  {content}
</div>
```

密集检查区使用 `compact`，导航列表使用空值。消息流、设置与文档等主要阅读区
保留普通裁切。不要用于输入框、终端、编辑器、图片/PDF 画布或横向滚动区。
固定标题、输入区和菜单留在遮罩节点之外。该工具占用 `animation` 和 `mask-image`，
接入前先检查冲突。

原生自身滚动时间线仅在边缘外还有内容时渐隐；没有溢出时不渐隐，极小视口的
每侧渐隐不超过视口一半。嵌套滚动节点相互独立。透明度遮罩不增加输入覆盖层，
保留原生滚动、选择和自动跟随。浏览器不支持相关特性、减少动态效果、强制颜色或
打印时回退为普通裁切。

检查短内容及溢出内容在顶部、中间、底部的状态；向展开的折叠区流式追加内容，
手动上翻、收起再展开、切换会话并调整窗口。核实跟随/暂停、可读性、键盘导航、
菜单与滚动条可用性，以及主要阅读区边缘没有渐隐。jsdom 不计算滚动时间线，
单元测试通过不能作为视觉批准。
