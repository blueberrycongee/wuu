# Wuu 品牌规范

Wuu 的品牌以墨与纸为基础，只有一个角色：小球。它的识别和状态全部由眼睛承担。其他 agent 和模型以同样的小球出现，使用七种 agent 色；Wuu 自己永远是墨色。完整手册是 [`brand/manual/index.html`](../../../brand/manual/index.html)，在浏览器中打开阅读；源文件、资产和生成器在 [`brand/`](../../../brand/README.md)。

这份规范定义品牌识别，并展示应用提案。它不修改桌面应用、官网或本文档站；在这些地方采用品牌需要另行评审。

![手册封面](../../en/assets/brand/manual-cover.png)

## 小球

| 用法 | 颜色 | 眼睛 |
| --- | --- | --- |
| 品牌符号：标识、应用图标、官网、文档 | 墨色（深色背景上用纸色） | 固定的品牌姿态，看向右上 |
| 工作中的 Wuu：会话里 Wuu 自己的头像 | 墨色（暗色主题为纸色） | 随活动状态变化 |
| 其他 agent：子 agent、项目 agent、模型、服务商 | 七种 agent 色之一 | 随活动状态变化；眼睛为墨色 |

- 眼睛永远不居中竖直：圆面上两条竖直的胶囊就是暂停按钮。偏向一侧的视线，才让它成为一张脸。
- 按实际渲染直径选择光学尺寸：大于 40 px 用展示版，21–40 px 用小尺寸版，20 px 及以下用微型版（16 px 时每只眼睛落在整数像素上）。
- 小球不是吉祥物、通用加载图标或装饰。一个版面最多一只品牌小球；agent 小球群除外。
- 不加嘴、腮红、四肢、渐变、高光、投影或描边；品牌符号不戴产品配饰。

## 文字标识与组合

字标 “wuu” 由同一只碗形画成：w 是两只碗共用一根更短、更细的中笔，u 是同一只碗加一根平切的尾笔。只使用提供的文件，不要用任何字体重新排。正文里中英文都写 **Wuu**，命令写 `wuu`。

组合的尺寸以字标 x 高度 X 为单位。横式组合是默认版本（球 1.4 X，间距 0.34 X）；竖式适合接近正方形的版面。组合四周留 1 X 安全空间，小球四周留 0.25 D。横式组合在屏幕上的最小 x 高度为 7 px，印刷最小宽度为 14 mm；小球的最小尺寸为 12 px 和 4 mm。

![组合方式](../../en/assets/brand/manual-lockups.png)

## 色彩

每组颜色只做一件事：

| 组 | 表示 | 用于 | 不用于 |
| --- | --- | --- | --- |
| 墨 `#141411` 与纸 `#F7F7F4` | 这是 Wuu | 标识、Wuu 的小球、主按钮、正文 | 换成其他色相或渐变 |
| 石色中性色 | 内容结构 | 底色、表面、分隔线、次要文字、选中态 | 用低对比度灰字承载必要信息 |
| agent 色 | 哪个 agent | 其他 agent 的球身、插画、按 agent 区分的图表 | 文字、控件、状态、Wuu 自己 |
| 状态色 | 发生了什么 | 成功、警告、错误、信息，总是配文字或图标 | 装饰 |
| 交互 | 可以操作 | 墨色主按钮、2 px 蓝色焦点环 | 给每个选中项上色 |

中性色按与底色的对比度选取，而不是等距取值：正文 17.2 : 1，次要文字 8 : 1，三级文字 4.8 : 1，占位文字 3 : 1。agent 色的 OKLCH 明度都是 0.84，没有哪个更抢眼；状态色更深、更饱和，两者不会被误读。agent 失败时球身不变色，失败由眼睛姿态、红色文字和图标表达。

## 字体与排版

| 字体 | 用途 | 授权 |
| --- | --- | --- |
| Hanken Grotesk | 品牌传播中的拉丁字母标题与正文 | SIL OFL 1.1，随仓库分发于 `brand/fonts/` |
| 思源黑体 Source Han Sans SC / Noto Sans CJK SC | 中文 | SIL OFL 1.1，从官方发布获取 |
| Fragment Mono | 命令、路径和变量名；关闭连字 | SIL OFL 1.1，随仓库分发于 `brand/fonts/` |
| 系统界面字体 | 产品界面，跟随用户设置 | 操作系统自带 |

中文与英文之间、数字与单位之间加空格。中文句子用全角标点，命令和路径用等宽字体，强调用字重而不是斜体。

## 动效

眼睛先动，身体几乎不动。动效沿用产品现有的时长以及 ease-out、ease-in 缓动。

| 动作 | 时长 | 什么时候 |
| --- | --- | --- |
| 视线转移 | 180 ms，ease-out | 状态改变 |
| 眨眼 | 60 + 40 + 90 ms，间隔 3.8–8.2 s | 空闲、聆听、等你确认 |
| 回落 | 280 ms，压扁不超过 6 % | 一轮任务完成时，只发生一次 |
| 工作中微动 | 周期 1600 ms | 只在思考和执行期间 |

产品现有的 15 种活动归为八个姿态：空闲、聆听、思考、工作、等你确认、完成、失败和暂停。开启减少动态效果（系统设置或应用内的动效设置）时，状态直接切换到最终姿态，没有眨眼、回落和循环；姿态与旁边的文字仍然表达状态。参考实现与演示在 [`brand/assets/motion/`](../../../brand/assets/motion/wuu-ball.js)。

## 应用

应用图标让小球坐在图标主体的底边上，只露出穹顶和眼睛。这是小尺寸下唯一允许的裁切。在封面、官网首屏、社交图等大幅面上，小球可以被一到两条边裁切，但两只眼睛必须完整可见，文字不能压在球上。

## 维护

所有数值只在 `brand/tokens/tokens.json` 定义一次。修改后运行 `npm --prefix brand run build` 和 `npm --prefix brand run render`（见 [`brand/README.md`](../../../brand/README.md)），并检查重新生成的手册与预览图。不要手改导出文件。产品自身的设计基础仍以[设计系统](design-system.md)为准；产品变量只通过该流程修改。

尚未验证：商标可用性、用户研究、应用图标在真实 macOS 程序坞中的效果、印刷色、Windows 与 macOS 上的渲染，以及 agent 色的色觉模拟。
