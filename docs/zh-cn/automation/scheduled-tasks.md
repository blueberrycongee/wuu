# 自动化

自动化按计划在指定工作区执行任务说明，适合定期检查、汇总或一次性跟进。设备需要保持
唤醒，Wuu 正在运行，并启用 Automation 插件。

## 新建自动化

1. 打开**自动化**。如果没有入口，检查内置 Automation 插件是否可用且已启用。
2. 在页面顶部选择**工作区**，确定任务运行位置，不会切换当前打开的会话。
3. 选择**新建自动化**，填写名称和任务内容，也可以从**建议**开始。
4. 在**运行于**中选择**每次新会话**，或搜索一个已有会话。
5. 选择每天、工作日、每周或**自定义**。时区、**仅执行一次**和**隔离运行**在**更多设置**中。
6. 选择**创建**保存。

任务说明应写清范围、期望结果和限制，例如：

```text
检查这个工作区中过去一天新增的 TODO。按文件汇总未解决的项目，不要修改文件。
如果没有新增 TODO，直接说明。
```

## 时间与运行方式

计划使用任务时区，创建时默认采用系统时区。自定义计划接受五段式 Cron，例如
`0 9 * * 1-5` 表示工作日 9:00。时区使用 `Asia/Shanghai` 等 IANA 名称。约每 15 秒
检查一次到期任务，不保证精确到秒开始执行。

**每次新会话**会在所选工作区创建可见会话。开启**隔离运行**后，每次运行使用基于项目
当前 `HEAD` 的独立 Git worktree，不包含未提交改动。打开创建的会话检查结果。

选择已有会话会沿用它的上下文；会话忙碌时，自动化消息排在当前工作之后。已有会话保留
自己的工作区，因此隔离运行只适用于新会话。Agent 的 `cron` 工具把这两种方式称为
`new_thread` 和 `thread_heartbeat`。

新会话模式可以重叠运行，不会自动等待上一次结束。并行修改时使用 worktree 隔离，或
选择已有会话，让后续工作在同一处排队。

## 管理任务和结果

选定工作区后，可以搜索，或按全部、已开启、已暂停、已完成筛选。选择任务编辑后点击
**保存修改**；关闭或切换任务会放弃未保存修改。**暂停**和**继续**控制后续触发，
**删除**在更多操作菜单中。删除任务不会删除已创建的会话，也不会停止其中正在运行的
工作；需要停止时，打开相应会话操作。

详情显示最近五次运行及失败信息。**已完成**展示仍保留运行记录的成功一次性任务快照，
快照只读。周期任务的一次成功不会让整个任务变为已完成。每个工作区最多保存 100 个
任务和最近 500 条运行记录。当前没有**立即运行**按钮。

## 没有运行或运行失败

确认当时 Automation 插件已启用、Wuu 正在运行、设备未休眠、任务未暂停，且工作区仍然
存在，再检查时区和下次运行时间。模型可用性、额度、网络和权限也可能造成失败，查看
运行错误及对应会话。

Wuu 恢复运行后，错过的一次性任务会补跑一次；周期任务漏跑的时间点会合并，不逐次
重放。一次性任务运行后会离开计划列表，到最近运行中查看结果。目标会话已不存在时，
重新选择已有会话，或改为**每次新会话**。

CI 或外部调度器使用 [`wuu exec`](exec.md)。
