# 工作区与项目

工作区将会话与本地文件夹关联起来。Agent 直接读取和修改该文件夹中的文件，因此应先选择项目，再发送任务。

## 添加工作区

在侧栏选择**添加工作区**。**使用现有文件夹**用于选择磁盘上已有的项目；**新建空白项目**会打开文件夹对话框，你可以在其中创建目录。这两个操作都不会把已有项目复制到 Wuu 中。

添加文件夹只是登记路径，不会上传整个项目。不过在执行任务时，Agent 可能把相关文件内容和工具结果发送给所选模型服务，详见[安全说明](../reference/security-model.md)。

## 不选择项目时

任务不属于某个已登记项目时，可以在**对话**中开始。这些会话使用 Wuu 管理的持久目录，仍然可以创建文件或打开终端。它们共用该目录，不会每次获得一个隔离文件夹。

如果成果需要保存在仓库中，请先添加并选择该仓库。已有产物需要移动时，明确告诉 Agent 目标位置；切换侧栏不会自动搬移文件。

## 切换项目

选择工作区可以查看它的会话或新建对话。重新打开已有会话会继续它原来的工作；切换前台工作区不会改变其他运行中会话的目标项目。

同一文件夹中的会话共享磁盘文件。对话历史彼此独立，不代表两个 Agent 不会修改同一文件。并行改动需要独立目录时，使用 [Git worktree 分叉](conversations.md#从较早消息分叉)。

## 移动或移除工作区

在磁盘上移动项目后，从工作区菜单选择**重新定位…**，指向新路径。Wuu 会更新路径，并保留状态和会话历史使用的项目身份。重新定位不会替你移动文件。文件夹不存在时，Wuu 会显示不可用，不会悄悄改用其他项目。

**移除工作区**只移除侧栏登记，不删除项目文件或已保存的会话。整理历史记录请使用[会话](conversations.md)中的归档和删除操作。

## 确认访问边界

使用 Wuu 引擎时，检查内容可选**只读**，需要编辑时选择**标准**。工具提示越界拒绝时，先检查目标路径和工作区登记，再考虑调整权限。工作区选择、Git 隔离和命令沙箱解决的是不同问题，详见[权限模式](../reference/permissions.md)。
