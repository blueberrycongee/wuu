# 工作区与项目

工作区对应一个本地文件夹。开始任务前先选好目录，避免 Agent 在错误的项目里修改文件。

## 添加工作区

在左侧栏的**工作区**区域选择**添加工作区**：

- **使用现有文件夹：**登记已有项目目录；
- **新建空白项目：**创建并登记一个新的空目录。

文件仍在原位置，添加工作区本身不会上传整个项目。执行任务时，提示词、相关文件内容和
工具结果可能发送给你选择的服务商，见[安全说明](../reference/security-model.md)。

暂时没有项目时，可以在**对话**中开始。无项目会话共用 Wuu 管理的持久目录，能创建
文件和打开终端；需要保留到自己的项目时，请明确要求保存到目标工作区。

## 切换和整理项目

选择侧栏中的项目名称查看它的会话，打开已有会话继续工作，或在该项目中新建对话。
多个会话可能同时修改同一文件夹；需要隔离文件时，使用[worktree 分叉](conversations.md#从较早消息分叉)。

目录移动或改名后，在工作区菜单中选择**重新定位…**，指向新目录。这样可以保留项目身份
和会话归属，无需重复添加一个同名项目。

**移除工作区**只移除侧栏登记，不会删除磁盘文件或已保存的会话。要整理历史记录，请使用
会话的归档或删除操作，见[会话与分支](conversations.md)。

## 工作区边界

检查代码时可选**只读**，需要修改时使用**标准**。遇到越界拒绝，先确认目标目录已添加为
工作区，不要直接改用无限制模式。命令沙箱和敏感路径限制见[权限模式](../reference/permissions.md)。

完成任务后，用[文件、diff 和终端](workspace-tools.md)检查结果。
