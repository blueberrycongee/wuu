# 项目

Project Agent 仍是实验功能，发布构建默认关闭，也没有开启设置。已有项目对话可以阅读，但不会执行或恢复排队工作。以下说明适用于显式启用功能的构建，见[开发指南](../project/development.md)。

项目提供一个主对话，处理目标、优先级、纠正和结果。协调者派发技术工作后结束自己的回合，调查、实现和审查由后台会话继续推进。主对话的工具仅用于协调和笔记，不能执行实现工具或阻塞等待成员。供应商响应延迟、限流仍可能影响答复速度。

协调、持久工作记录、投递、结果、停止和恢复属于 Wuu 核心能力，不依赖插件。

## 创建与组织工作

在侧栏“项目”分组点击 **+**，或在工作区菜单选择**新建项目**，说明目标、限制和交付授权：

```text
把目录搜索改成服务端分页。
保持现有公共 API，不修改数据库索引。
只在本地实现和测试，不提交、不推送。
```

协调者记录具有独立身份的工作，包括版本化需求、验收条件、授权范围和原始消息引用。同一目标的后续修改复用工作及其会话；独立目标可以拥有不同工作流。跨工作流的技术集成由指定技术负责人承担，协调者处理用户优先级和范围取舍。

每项工作有一个**技术负责人**，负责调查、方案、证据和技术验收。小任务可以直接完成；持续探索、修改和验证可以交给**持久执行者**。执行者跨阶段保留上下文和有用进程，提交准确的代码或内容版本，以及可访问的验证证据。负责人审查实际结果后才能验收。宿主记录谁验收了哪个结果，但不独立证明模型提供的证据正确。

Git 项目默认给每项工作建立隔离 worktree，负责人和执行者共享该目录。执行者运行时，宿主阻止负责人同时写入，并对参与者的修改工具加锁。非 Git 工作流共享工作区和项目写锁。文件隔离不能解决接口依赖，也不授予集成权限。

## 模型、用量与响应

协调者使用主对话模型。在**设置 → 运行时 → Project Agent 模型**中，选择技术负责人和持久执行者的默认模型。角色未配置时继承协调者模型；执行者还会沿用已有 Worker 默认配置。已经创建的会话保留原模型。负责人应具备足够判断能力，执行者可以选择能够可靠完成工作的经济模型。新建会话时可用模型别名明确覆盖默认选择。

执行者报告只发给技术负责人。只有验收结果和需要处理的工作阻塞会唤醒协调者。工具日志及普通状态变化由宿主更新界面，不生成额外的协调回合。后台会话共享项目并发容量，协调者不占该容量。等待超时不会取消后台工作。

项目面板按角色、服务商和模型展示持久记录的输入、输出及缓存输入 Token，包含旧成员用量。缓存输入不是额外输出。这些是用量记录，不是费用或省钱估计；比较时应包含所有角色、失败和重试，并采用相同验收标准。

## 查看进展与交付

输入框上方的项目状态入口打开右侧项目面板。每项工作分别显示调查、实现、验证、技术审查、已验收、已交付、阻塞或停止状态。展开后可以查看需求、授权、代码版本、证据和参与会话。投递回执区分已记录、等待注入和已被明确回合消费。对话回合结束不代表工作已经交付。

验收与交付分开。技术验收后，只有成果实际到达用户授权的目标位置，协调者才能记录交付。本地 worktree 可以是约定交付位置，但不证明已经提交、合并、推送、创建 PR 或部署；这些动作分别需要用户授权或针对该动作的既有工作流程。

## 纠正、停止与继续

在主对话中修改要求，协调者会更新完整工作契约、增加需求版本并使旧验收失效。旧排队输入在消费时被拦截，过期执行被中断，新需求送达技术负责人。正在运行的修改工具必须实际退出后才释放写锁。“已记录”不等于执行者已经采用新方向。

也可以直接给工作成员发消息。Wuu 会把消息保留在工作契约中，使之前的验收失效，并转给技术负责人。不希望修改工作要求的进度询问应放在主对话。

工作面板的**停止**撤销待处理指令并中断两个后台成员。停止某个工作成员也会停止整项工作；停止协调者当前回合则不会取消独立后台工作。**继续**会在同一组会话中明确重新发出当前契约。迟到的完成报告不能重启已停止工作。

重启后，Wuu 使用相同输入身份重试持久派发，并恢复有明确终态的结果，避免重复投递。缺少终态证据的执行会标为阻塞，需要检查并明确继续，不会假定成功。后台工作依赖 Wuu 执行进程保持运行，关闭电脑不等于远程执行。

## 旧项目与限制

已有 Side Agent 和 Worker 仍作为旧会话保留，可以访问、通信、纳入或移出项目；不会被静默改名为已经验收的工作。新工作采用版本化流程。移出工作绑定的成员会先停止该工作，本地文件保留。

Project Agent 暂不提供定时器、外部触发器或云端执行。归档项目不会停止成员。手机端可以打开成员对话，但尚未提供此工作面板。普通对话内的有界任务见[子代理](subagents.md)。
