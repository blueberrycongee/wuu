# 快捷键

在**设置 → 快捷键 → Vim 导航**中开启键盘导航。默认关闭，偏好保存在本机。标题栏的 **NORMAL** 表示导航模式，**INSERT** 表示输入框或编辑器正在接收按键。点击模式提示，或在导航模式按 `?`，可打开速查表。

## 阅读和会话

| 按键 | 操作 |
|---|---|
| `j` / `k` | 向下 / 向上滚动 |
| `Ctrl+d` / `Ctrl+u` | 向下 / 向上半页 |
| `gg` / `G` | 到顶部 / 底部 |
| `i` | 回到会话输入框 |
| `Esc` | 离开输入框或取消未完成的前缀 |
| `/` | 搜索会话 |
| `gt` / `gT` | 下一个 / 上一个已打开的会话或草稿，到末尾后循环 |
| `空格 n` | 在当前工作区新建会话；已有打开的草稿时回到该草稿 |
| `?` | 查看快捷键 |

阅读键滚动当前任务会话面板；设置打开时滚动设置页。`gt` 和 `gT` 按当前窗口中已打开的会话与草稿顺序切换；其他历史会话通过 `/` 查找。切换复用侧栏导航逻辑，保留各会话的草稿。

## 工作区工具

先按下并松开空格，再按第二个键。界面会显示可用命令提示。空格和 `g` 前缀需在两秒内接下一个键。按 Escape、点击鼠标、改变焦点或离开窗口都会取消前缀；长按前缀不会自动触发命令。

| 按键 | 操作 |
|---|---|
| `空格 s` | 显示或隐藏侧栏 |
| `空格 w` | 显示或隐藏工作区面板 |
| `空格 f` | 打开文件 |
| `空格 t` | 打开终端 |
| `空格 d` | 查看更改 |
| `空格 b` | 打开浏览器 |
| `空格 ,` | 打开常规设置 |

命令使用当前窗口和连接中可用的工具。独立弹出的会话窗口不打开工作区面板。

## 输入和焦点

Vim 导航作用于桌面工作台，不会将输入框或代码编辑器变成 Vim 文本编辑器。文本框、输入法组词、弹窗、菜单、终端、代码编辑器和内嵌浏览器页面保留自己的按键规则。触屏导航保持原样。

输入框中用于关闭菜单或停止生成的 Escape 优先；处理完后再按 Escape 离开输入框。终端或代码编辑器中的 Escape 仍由工具处理；点击会话区域移出焦点后，再使用工作台导航。按钮上的空格仍用于点击，Escape 可取消按钮焦点。

现有输入快捷键继续可用：Enter 发送，Shift+Enter 换行，支持排队时 Command/Ctrl+Enter 将草稿排队。Command/Ctrl+P 打开会话搜索。复制、粘贴、选择、撤销和 Tab 焦点切换保持原有行为。发送与停止的细节见[会话](conversations.md#任务运行时)。

移动按键参考 [Vim 速查表](https://vimhelp.org/quickref.txt.html)；空格前缀是 Wuu 的应用导航绑定。
