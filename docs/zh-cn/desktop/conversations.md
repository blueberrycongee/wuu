# 会话与分支

会话会保存消息和工具活动。继续同一项工作时，打开原会话；尝试另一条路线时，可以从
较早的消息分叉。

## 新建和继续会话

先选工作区，再新建对话。以后从侧栏打开原会话，直接说明下一步要做什么。
会话菜单可以重命名、置顶或归档。

归档只会把会话从默认列表隐藏；在**设置 → 归档**中可以筛选和恢复。删除会移除保存的
历史及 wuu 能定位到的会话产物，应只在确定不再需要时使用。

Collaboration 可以把实际工作交给普通 Harness 会话。你可以从 Collaboration 打开同一个
会话，查看进度或继续聊。只查看不会接管；输入并发送消息后会接管，暂停 Collaboration
对该会话的自动指令和跟进。详见[协作说明](collaboration.md)。

## 任务运行时

任务运行时，可以在输入框补充消息：

- **Enter：**立即补充信息或调整当前任务方向。
- **Tab：**排队，等当前轮次结束后处理。
- **Shift + Enter：换行。**

输入框为空或当前没有任务运行时，Tab 保持普通焦点切换；打开 `/` 菜单时，Enter 和 Tab
用于选择命令。

需要中断时点击停止按钮。补充消息或停止任务都不会撤销已经执行的命令和文件改动。
先检查[当前 diff](workspace-tools.md#审查)，再决定怎样继续；后台命令的状态也应单独确认。

## 从较早消息分叉

在历史消息上选择**分叉**，可以从那个时间点创建新会话：

- **派生到本地：**新会话继续使用原文件夹，文件改动由两个会话共享。
- **派生到 git worktree：**从当前 Git `HEAD` 创建独立目录，不包含原目录中未提交的改动。

分叉复制到所选消息为止的对话历史，不会把磁盘恢复到那条消息时的状态。需要带上当前
改动时，先检查并提交，再创建 worktree；不支持 worktree 时，选项会显示不可用原因。

## 侧聊

输入 `/side` 打开侧聊，可以询问当前任务、解释输出或比较方案，内容不会加入主对话。
需要长期继续的工作请新建会话或分叉；当前执行方式不支持侧聊时，入口会显示原因。

## CLI 中的会话

```bash
wuu session list
wuu session show --last
wuu session search "关键词"
wuu exec --continue "继续最近的会话"
wuu exec resume THREAD_ID "继续这个任务"
```

自动化任务不需要保存会话时使用 `wuu exec --ephemeral`。完整选项见
[`wuu exec` 指南](../automation/exec.md)。
