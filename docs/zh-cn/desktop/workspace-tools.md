# 文件、改动、终端与浏览器

桌面端把检查任务成果需要的工具放在当前工作区旁边，方便你核实 Agent 的实际改动和
验证结果。

## 文件

打开**文件**面板或输入 `/files` 浏览项目树。选择文件后可以在标签页中查看文本、代码、
图片和受支持的文档。文件面板显示的是当前磁盘状态，不是某条消息的历史快照。

## 审查

打开**审查**面板或输入 `/diff` 查看当前 Git 工作区的变更。提交或发布前至少确认：

- 只修改了预期文件；
- 没有调试内容、生成垃圾或敏感信息；
- 删除和重命名符合预期；
- Agent 声称运行的验证确实有对应结果。

消息中的单轮文件变化和工作区当前总 diff 可能不同：后续任务可能再次修改同一文件。
最终检查以磁盘和 Git 当前状态为准。

## 终端

打开**终端**面板或输入 `/terminal` 使用当前工作区的 shell。Agent 启动的命令及后台
进程也会在消息流中留下活动和结果；长输出可能保存为日志引用，而不是全部展开。

你在终端中手动输入的命令使用当前系统用户的权限，即使 Agent 处于只读模式也一样。
Agent 执行命令受所选[权限模式](../reference/permissions.md)约束；不要因为 Agent
无法执行，就把未经检查的命令复制到终端运行。

## 浏览器

浏览器面板用于在工作区旁查看网页。Agent 操作网页时，选择**接管浏览器**可以手动
操作，再选择**交还浏览器给 Agent**交还控制权；**停止浏览器 Activity**结束本次自动化。
自动操作网页需要当前运行环境和工具支持。

内置浏览器可以单独使用 Clash 等本地代理，不会改变 app-server 或模型服务的网络连接。启动桌面端前设置 `WUU_BROWSER_PROXY`，例如 Clash Verge 常见的混合端口：

```bash
WUU_BROWSER_PROXY=http://127.0.0.1:7897 npm run dev --prefix desktop
```

打包版可以从终端传入同名环境变量后启动应用。代理只作用于 Wuu 内置浏览器使用的 session；如果代理端口不可用，桌面端和 API 服务仍会正常启动，但浏览器请求会失败，修正端口后重启桌面端即可。

## 用 `/` 找入口

在输入框中键入 `/` 可以搜索当前版本提供的操作、工作流和 Skills。菜单会根据当前
工作区、任务是否正在运行以及 runtime 能力禁用不适用项，因此它比静态命令清单更可靠。
