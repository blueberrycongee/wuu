# 文件、改动、终端与浏览器

工作区面板用于检查任务实际产生的结果。会话记录 Agent 做过什么，文件和 Git diff 则反映磁盘上现在是什么。

## 文件

打开**文件**或输入 `/files` 浏览项目。选择文件后，可以查看受支持的文本、代码、图片和文档。这里显示当前文件，不是较早消息发送时的内容。

### Agent 文件搜索

Agent 的 `grep` 和 `glob` 工具在省略 `offset` 或传入 `0` 时搜索当前文件。外部编辑文件或重新打开会话后也一样；旧搜索缓存不能证明文件没有变化。

后续分页是快照续页，不是刷新。保持搜索参数一致，并同时传入 `page.next` 中的 `offset` 和 `expected_revision`。缺少或不匹配的 token 会被拒绝。即使工作区 revision 摘要不变，新的首页也可能使旧续页失效。遇到 stale 错误时，从 `offset: 0` 重新搜索，不要携带 `expected_revision`。搜索反映读取时的文件内容，不保证并发编辑期间的原子文件系统快照。

## 交付产物

Agent 可以把你请求的图片、图表或文档作为独立产物展示在会话中。图片（包括 SVG）直接显示，点击可放大；其他文件显示为产物卡片。

点击图片可打开预览。触摸板捏合或按住 Ctrl/Command 滚动，可围绕光标位置缩放；双指滚动或拖动可移动放大的图片。双击可放大或恢复适应窗口。工具栏提供**适应窗口**、**原始尺寸**、**旋转**和**图片另存为…**。另存为可选择文件名和目录，并保留原始文件及动画；预览中的旋转不会修改保存的图片。

快捷键：**+ / −** 缩放，**0** 适应窗口，**1** 原始尺寸，**R** 旋转，方向键平移，**Command/Ctrl + S** 保存，**Esc** 关闭预览。

产物保存的是快照。之后修改或删除源文件，不会改变已交付版本。普通文件链接或 diff 不等于产物快照。

在桌面端，点击文件产物卡片会在会话旁的工作区标签页中打开快照。PDF、HTML、图片、音频和文本使用相应的预览器，其他格式仍提供下载操作。HTML 预览不执行脚本。文本预览最多读取 2 MiB，更大的文件可下载后用其他应用打开。

当前轮次成功结束且只交付一个文件时，桌面端可以在确认快照可用后自动打开预览。自动预览支持不超过 20 MiB 的 PDF、HTML、图片和文本，其中非 HTML 文本上限为 2 MiB。普通链接和文件编辑不会触发自动预览。多个文件、不支持的格式、失败或中断的轮次以及历史会话都需要手动点击。

自动预览不会占用正在使用的面板或抢占前台浏览器。在本轮中操作面板、打开浮层或切换到窄窗口，会抑制这一轮的自动展开。切换会话或工作区会取消尚未完成的预览检查；关闭预览后，后续更新不会再次打开它。下载始终需要明确操作。

Agent 和集成程序可以通过内置 `present_artifact` 工具展示已有本地文件：

```json
{"path":"output/chart.svg"}
```

文件大小上限为 256 MiB，仍受读取权限和敏感路径限制，工具不会下载 URL。展示文件不会检查其视觉效果，也不会把图片字节发送给模型；视觉验证需要单独完成。

## 审查

打开**审查**或输入 `/diff` 查看当前 Git 改动。提交前检查变更路径、增删内容和敏感信息，并将 Agent 声称完成的检查与实际命令结果对照。

单轮消息中的 diff 可能与工作区当前 diff 不同，因为后续任务可能再次修改同一文件。最终审查应以仓库当前状态为准。

## 终端

打开**终端**或输入 `/terminal` 在工作区运行 shell。手动输入的命令使用你的系统权限，即使 Agent 处于只读模式也一样。运行前请检查命令，不要只是为了绕过 Agent 的权限拒绝而复制到终端执行。

Agent 执行的命令也会在会话中留下活动和结果。长输出可能保存为日志引用。长时间运行的进程可以通过进程控件查看输出、发送输入或停止，详见[命令与后台任务](../reference/agent-command-system.md)。

## 浏览器

打开**浏览器**或输入 `/browser`，在会话旁的工作区面板中打开网页。这个面板和 Agent 正在用的页面是同一个标签：地址栏、后退、前进和刷新都作用在这一页上。点击消息里的网址、轮次「来源」胶囊，或过程区里紧凑的浏览活动，也会打开或聚焦这个面板，并导航到对应页面。按住 Command（Windows 上为 Ctrl）或用中键点击，仍可在系统浏览器中打开。如果你正在使用其他工作区工具，页面仍会在这个标签里导航，但不会抢走面板焦点。

桌面端默认提供浏览器自动化。当前会话会自动在消息栏里用悬浮卡片预览 Agent 正在操作的页面，后台浏览操作也会显示；切换会话后会隐藏。预览不需要显式请求可见，后续操作也不会让它消失。隐藏或最小化 Wuu 时卡片也会隐藏，显示或恢复窗口后会重新出现。拖拽后卡片吸附到这一栏的角落，并避开输入框。页面保持原来的排版尺寸，并缩小到整页都能落在卡片里。拖边缘或角落改变卡片大小时，这个缩放会跟着变。在卡片上只能移动或缩放它，点不到页面里面，也不能滚动。卡片不绘制页面滚动条。要滚动或接管，先把这一页展开到侧栏。右侧面板不会因此自动打开或关闭。你自己打开浏览器，或在卡片上展开，这一页就停靠到侧栏；地址栏、后退、前进和刷新都作用在这一页上。点页面、改地址或使用导航按钮会接管，页面留在面板里。**接管浏览器**切换为手动操作，**交还浏览器给 Agent**恢复 Agent 控制并继续显示这一页，**停止浏览器 Activity**停止该活动。启动前设置 `WUU_ENABLE_BROWSER=0` 可隐藏该自动化工具。

悬浮预览和工作区面板使用同一个动画指针。页面缩小时，指针仍保持清晰；执行操作前会先移到目标，并显示点击、输入和滚动反馈。接管或停止活动时会清除指针。开启减少动态效果后，不播放移动和停留动画。

如果只需要让内置浏览器使用代理，在启动桌面应用前设置 `WUU_BROWSER_PROXY`。源码构建示例：

```bash
WUU_BROWSER_PROXY=http://proxy.example:7897 npm run dev --prefix desktop
```

请换成你自己的代理地址和端口。此设置不控制模型 API 或 app-server 的流量。启用后浏览器请求失败时，先检查代理，再用正确配置重启 Wuu。

## 查找操作入口

在输入框键入 `/` 可以搜索工作区操作、提示词快捷方式和技能。不可用的选项会说明缺少什么条件，例如工作区、空闲会话或引擎支持。
