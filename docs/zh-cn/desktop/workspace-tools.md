# 文件、改动、终端与浏览器

工作区面板用于检查任务实际产生的结果。会话记录 Agent 做过什么，文件和 Git diff 则反映磁盘上现在是什么。

调整窗口大小或界面缩放时，左侧栏会保留你选择的展开状态和宽度。可通过侧栏按钮或拖动分隔线收起它。

展开右侧面板后，当前会话会成为工具标签前的第一个标签。点击它可以在展开布局中返回会话，再点击工具标签即可切回工具，草稿会保留。退出展开模式后，会话和工具恢复并排显示。

## 侧边聊天

使用 `/side` 或**在侧边聊天中提问**，会在右侧栏打开侧聊标签，与文件和其他工具共用侧栏宽度和展开布局。从文件选区发起提问时，侧聊保留引用卡片，原文件仍可通过标签返回。

侧聊跟随当前选中的主会话，每个会话分别保留自己的侧聊记录和草稿。切换工具标签或收起右侧栏会保留草稿，正在生成的回答继续运行。关闭侧聊标签会保留记录；停止生成和清空聊天仍使用侧聊中的独立操作。展开布局中，侧聊标签使用自己的输入框，主会话可通过第一个标签返回。

## 界面缩放

在 macOS 上按 **Command + + / −**（其他平台用 **Ctrl + + / −**）缩放整个桌面界面。
**Command/Ctrl + =** 也可放大，**Command/Ctrl + 0** 恢复到 100%。
缩放范围为 50%–200%，每次调整 10 个百分点，窗口中央会短暂显示当前百分比。
缩放设置在重新启动后保留，与界面及代码字体大小设置相互独立。
这些快捷键作用于 Wuu 窗口，不接管内嵌浏览器页面。

## 文件

打开**文件**或输入 `/files` 浏览工作区。选择文件后，可以查看受支持的文本、代码、图片和文档。这里显示当前文件，不是较早消息发送时的内容。

在单会话中打开工作区文件后，会话内容保持可见，输入框移到右侧预览底部。从这里发送的请求会携带当前选中文件作为上下文。草稿仍属于当前会话，关闭预览后会回到会话输入框。阅读时可最小化、恢复浮动输入，也可通过预览中的会话菜单返回完整对话。需要更多阅读空间时，可手动展开为全面板。

预览当前会话交付的 PDF 时，输入框会把该交付快照作为 PDF 附件随请求发送；预览工作区文件时，则传递当前文件的工作区路径。切换到其他工具后，后续请求不会继续隐式携带先前预览的文件。

### Agent 文件搜索

Agent 的 `grep` 和 `glob` 工具在省略 `offset` 或传入 `0` 时搜索当前文件。外部编辑文件或重新打开会话后也一样；旧搜索缓存不能证明文件没有变化。

后续分页是快照续页，不是刷新。保持搜索参数一致，并同时传入 `page.next` 中的 `offset` 和 `expected_revision`。缺少或不匹配的 token 会被拒绝。即使工作区 revision 摘要不变，新的首页也可能使旧续页失效。遇到 stale 错误时，从 `offset: 0` 重新搜索，不要携带 `expected_revision`。搜索反映读取时的文件内容，不保证并发编辑期间的原子文件系统快照。

## 交付产物

Agent 可以把你请求的图片、图表或文档作为独立产物展示在会话中。图片（包括 SVG）直接显示，点击可放大；其他文件显示为产物卡片。

点击图片可打开预览。触摸板捏合或按住 Ctrl/Command 滚动，可围绕光标位置缩放；双指滚动或拖动可移动放大的图片。双击可放大或恢复适应窗口。工具栏提供**适应窗口**、**原始尺寸**、**旋转**和**图片另存为…**。另存为可选择文件名和目录，并保留原始文件及动画；预览中的旋转不会修改保存的图片。

快捷键：**+ / −** 缩放，**0** 适应窗口，**1** 原始尺寸，**R** 旋转，方向键平移，**Command/Ctrl + S** 保存，**Esc** 关闭预览。

产物保存的是快照。之后修改或删除源文件，不会改变已交付版本。普通文件链接或 diff 不等于产物快照。

在桌面端，点击文件产物卡片会在会话旁的工作区标签页中打开快照。PDF、HTML、图片、音频和文本使用相应的预览器，其他格式仍提供下载操作。HTML 预览不执行脚本。文本预览最多读取 2 MiB，更大的文件可下载后用其他应用打开。

当前轮次成功结束且只交付一个文件时，桌面端可以在确认快照可用后自动打开预览。自动预览支持不超过 20 MiB 的 PDF、HTML、图片和文本，其中非 HTML 文本上限为 2 MiB。普通链接和文件编辑不会触发自动预览。多个文件、不支持的格式、失败或中断的轮次以及历史会话都需要手动点击。

自动预览不会占用正在使用的面板或抢占前台浏览器。在本轮中操作面板、打开浮层或切换到窄窗口，会抑制这一轮的自动展开。切换会话或工作区会取消尚未完成的预览检查；关闭预览后，后续更新不会再次打开它。下载始终需要明确操作。

Agent 和集成程序可以通过内置 `present_artifact` 工具展示已有本地文件：

```json
{"path":"output/chart.svg"}
```

文件大小上限为 256 MiB，仍受读取权限和敏感路径限制，工具不会下载 URL。展示文件不会检查其视觉效果，也不会把图片字节发送给模型；视觉验证需要单独完成。

在 Markdown、代码或纯文本预览中选中文字，可以使用**添加到对话**、**评论**或**编辑**。
添加到对话会在输入框上方的附件栏中显示引用卡片，不会自动发送或把原文展开到输入区。
打开卡片可查看原文，点击卡片上的移除按钮可移除片段；发送消息时会带上原文及来源位置。
评论显示在文档预览底部，并在附件栏中显示为
引用卡片；打开卡片可以查看位置、引用原文和评论。发送前可以修改、删除评论，
也可以把多条评论随一条消息一起发送。

在文件选区中选择**在侧边聊天中提问**，可以把原文带入侧聊的问题。此操作需要已有主对话；侧聊输入框会显示相同的引用卡片。

**编辑**会在选区附近展开编辑要求输入框。提交后向当前会话发送独立请求，保留主输入框中的
草稿和附件；任务正在运行时，请求会排队。请求会要求 Agent 修改前读取最新文件，预览在该轮任务结束后
刷新。提交失败时，编辑要求留在原处，方便重试。

来源位置对应选中文字时的文件版本。文件发生变化后，评论仍保留原来的引用内容。复杂的渲染
块无法精确对应源码时，会引用整个块。这些选区操作暂不适用于 PDF 和图片预览。

## 审查

打开**审查**或输入 `/diff` 查看当前 Git 改动。提交前检查变更路径、增删内容和敏感信息，并将 Agent 声称完成的检查与实际命令结果对照。

变更文件按文件夹分组，列表随工作区变化自动刷新。面板较宽时，diff 显示在列表旁；面板较窄时，选择文件打开 diff，用返回按钮回到列表。diff 标题栏中，箭头切换到上一个或下一个文件，圆圈把文件标记为已查看，铅笔在编辑器中打开文件。文件状态或增删行数改变后，已查看标记会清除；Wuu 重启后不保留这些标记。状态和增删行数相同的编辑不会清除标记，提交前仍需检查当前 diff。

单轮消息中的 diff 可能与工作区当前 diff 不同，因为后续任务可能再次修改同一文件。最终审查应以仓库当前状态为准。

## 终端

打开**终端**或输入 `/terminal` 在工作区运行 shell。手动输入的命令使用你的系统权限，即使 Agent 处于只读模式也一样。运行前请检查命令，不要只是为了绕过 Agent 的权限拒绝而复制到终端执行。

Agent 执行的命令也会在会话中留下活动和结果。长输出可能保存为日志引用。长时间运行的进程可以通过进程控件查看输出、发送输入或停止，详见[命令与后台任务](../reference/agent-command-system.md)。

## 浏览器

打开**浏览器**或输入 `/browser`，在会话旁的工作区面板中打开网页。这个面板和 Agent 正在用的页面是同一个标签：地址栏、后退、前进和刷新都作用在这一页上。点击消息里的网址、轮次「来源」胶囊，或过程区里紧凑的浏览活动，也会打开或聚焦这个面板，并导航到对应页面。按住 Command（Windows 上为 Ctrl）或用中键点击，仍可在系统浏览器中打开。如果你正在使用其他工作区工具，页面仍会在这个标签里导航，但不会抢走面板焦点。

桌面端默认提供浏览器自动化。当前会话会自动在消息栏里用悬浮卡片预览 Agent 正在操作的页面，后台浏览操作也会显示；切换会话后会隐藏。预览不需要显式请求可见，后续操作也不会让它消失。隐藏或最小化 Wuu 时卡片也会隐藏，显示或恢复窗口后会重新出现。拖拽后卡片吸附到这一栏的角落，并避开输入框。页面保持原来的排版尺寸，并缩小到整页都能落在卡片里。拖边缘或角落改变卡片大小时，这个缩放会跟着变。在卡片上只能移动或缩放它，点不到页面里面，也不能滚动。卡片不绘制页面滚动条，也不会自动打开侧栏。打开浏览器或展开卡片后，就能在面板里操作同一页。启动前设置 `WUU_ENABLE_BROWSER=0` 可隐藏该自动化工具。

在 Agent 的页面里点击或输入、提交地址，或使用导航按钮，会暂停当前任务，页面留在面板里供你操作。仅悬停或滚动不会暂停任务。准备继续时，在对话里发送下一条指令；后台更新不会恢复浏览器操作权限。需要中断任务时，使用对话中的停止操作。浏览器不再提供独立的交接按钮或控制权状态栏。

悬浮预览和工作区面板使用同一个动画指针。页面缩小时，指针仍保持清晰；执行操作前会先移到目标，并显示点击、输入和滚动反馈。直接操作页面时会清除指针。开启减少动态效果后，不播放移动和停留动画。

如果只需要让内置浏览器使用代理，在启动桌面应用前设置 `WUU_BROWSER_PROXY`。源码构建示例：

```bash
WUU_BROWSER_PROXY=http://proxy.example:7897 npm run dev --prefix desktop
```

请换成你自己的代理地址和端口。此设置不控制模型 API 或 app-server 的流量。启用后浏览器请求失败时，先检查代理，再用正确配置重启 Wuu。

## 查找操作入口

在输入框键入 `/` 可以搜索工作区操作、提示词快捷方式和技能。不可用的选项会说明缺少什么条件，例如工作区、空闲会话或引擎支持。

## macOS 应用快照

应用快照是按需启用的只读功能，可将一个可见的应用窗口添加为对话附件。它需要 macOS 14 或更新版本，以及包含 Wuu App Snapshot 辅助程序的桌面构建。

打开输入框的 **+** 菜单，选择**应用快照…**，设置并启用快捷键。截图需要屏幕录制权限；可选的窗口文字还需要辅助功能权限。在**系统设置 → 隐私与安全性**中，授权系统列出的 Wuu 或 Wuu App Snapshot。这些权限不会启用自主 Computer Use。

保持 Wuu 主窗口开启，切换到需要共享的应用窗口，再按快捷键。快捷键会先同步确定目标窗口，再启动捕获辅助程序。捕获完成前保持该窗口在前台。Wuu 随后会打开包含截图和可选文字的本地预览。检查内容，再选择**添加到草稿**。只有发送消息时，快照才会共享给所选的模型服务。可读取的文字可能包含可见滚动区域以外的内容；安全辅助功能字段会被跳过。截图不会自动遮盖敏感内容，添加前请检查所有可见内容。目前仅在窗口 API 与辅助功能 API 可明确对应到同一个单窗口应用时附加文字；多窗口应用或无法确认的情况只提供截图。

捕获期间再次按快捷键可取消，关闭预览会丢弃快照。关闭或重新加载 Wuu 主窗口也会取消捕获并使预览失效；延迟结果不会重新打开替代窗口。若目标窗口变化、关闭或失去捕获权限，Wuu 会丢弃本次结果，不会改为捕获其他应用或整个屏幕。关闭快捷键会停止正在进行的捕获并清除预览，但不会撤销 macOS 权限；权限仍由系统设置管理。

快捷键默认关闭，不会记录后台历史或音频。使用临时签名的预览构建更新后，可能需要重新授权。原生捕获与权限行为需要在 macOS 上验收，仅浏览器或 Electron 界面检查不能证明这些能力可用。
