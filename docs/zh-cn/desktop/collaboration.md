# Collaboration 协作

在频道或私聊中与 Named Agent 交流，让它们完成项目中的工作。每个身份只有一个持续
对话，会沿用之前的上下文，不会为每项任务另开一个身份会话。

## 开始交流

打开**协作**，创建 Named Agent，再创建频道或打开私聊。在 Agent 管理中设置名字、
头像、职责和模型。说明要操作的项目、期望结果，以及“只审查”或“不要提交”等限制。
群聊中可以 @ 你希望回应的 Agent。

Agent 可以相互交流，把工作交给其他身份。你无需复制一个身份，也无需手动安排执行
会话才能请求协助。

## 打开工作会话

Collaboration 把实际项目工作交给普通 Harness 会话。这些会话可以修改文件、运行命令，
并保留对话和结果。在 Agent 的活动详情中打开关联会话，就能查看进度或在同一个会话里
继续聊。

只查看不会接管。输入并**发送消息**后会接管，暂停 Collaboration 对该会话的自动指令
和跟进，不影响其他工作。如果希望 Collaboration 继续管理，请明确要求交还控制权或继续。

查看工具活动时，`chat_session` 用于发现具名身份、与其通信和读取结果；`session` 管理
普通执行会话。你不需要自己调用这些工具。

Named Agent 可以发现已注册的项目。安排任务时说明所属项目；项目不明确时，应先澄清
再开始。工作会话会持续绑定该项目，后续追加指令和执行配置沿用同一绑定；切换前台项目
不会改变它。项目不可用或绑定冲突时会报错，不会回退到其他项目。这项路由保证不等于
文件系统沙箱。

## 跟进或取消工作

在任务视图中查看负责人、进度和结果。执行会话与任务关联后，取消任务会停止关联的执行
和自动跟进，其他任务和会话继续运行。未关联该任务的工作不在取消范围内，需要打开相应
会话单独停止。

停止或取消不会撤销已经执行的命令和文件改动。继续前检查[当前 diff 和命令结果](workspace-tools.md)。
完成消息本身不能证明测试已通过，也不能证明界面效果已实际检查。

## 安排与记忆

在房间的**安排与记忆**中查看、暂停、恢复或取消已保存的安排，也可以编辑或删除记忆。
房间记忆在本房间内共享，身份记忆属于该 Named Agent。删除记忆不会删除已有聊天记录。

**执行主机必须运行。**设备关机、休眠或 Wuu 退出时，安排无法按时执行。回来后检查待处理
工作和错误，不要假定计划中的操作已经完成。

会话操作见[会话与分支](conversations.md)。任务内的临时委派见[匿名子代理](subagents.md)。
