# 协作

协作提供频道和私聊，用于与具名 Agent 持续开展工作。一个 Agent 身份拥有持续对话，也可以管理多个工作会话，因此既能沿用前情，又不必把所有任务塞进同一个执行会话。

## 从一个具名 Agent 开始

打开**协作**，创建 Agent，设置名字、头像、职责和模型，然后打开私聊或将它加入频道。群聊中可以 @ 希望回应的 Agent。

说明目标项目、期望结果和工作限制，例如：

```text
审查 catalog 项目的搜索改动。发现回归问题时给出文件位置和原因。
不要修改文件，也不要创建提交。
```

具名 Agent 可以发现已登记项目，并与其他身份交流。明确项目很重要：切换前台工作区不会重新分配已经绑定到其他项目的工作会话。

当用户消息与后台回报同时待处理时，Agent 会在下一个协调回合优先处理用户指令。工作会话继续独立运行，较早的回报仍保留在原房间与任务的队列中。

## 查看实际执行

项目工作在普通工作会话中执行，工具活动中也称为 Harness 会话。从 Agent 的活动详情打开关联会话，可以查看文件改动、命令和结果。该会话持续绑定自己的项目和执行配置；项目不可用或绑定冲突时会报错，不会退回其他项目。

会话回报会区分执行完成、失败和中断。控制权变化或普通证据消息不会被标记为执行成功。执行回合结束也不会自动完成任务，具名 Agent 仍需根据你的要求判断结果。

只查看不会接管，发送消息才会。接管后，Wuu 暂停协作对该会话的自动指令和跟进，让你直接继续工作。需要具名 Agent 再次管理时，请明确要求它恢复管理。

工具活动中的 `chat_session` 负责具名身份之间的通信，`session` 负责普通执行会话。你可以直接用自然语言安排工作，不需要自己调用这些工具。

委派任务时，具名 Agent 可以选取当前频道或私聊中的图片与受支持附件。工作会话收到保存的媒体和来源上下文，未选中的附件不会自动转发。证据失效、无权访问或模型不支持时会报错，应先选择兼容模型或重新附上证据，再继续工作。开发者可查阅[媒体交接契约](../automation/app-server.md#named-agent-媒体交接)。

## 跟进和取消任务

任务视图显示负责人、进度和结果。取消任务会停止与它关联的执行和跟进，其他会话继续运行。没有任务关联的会话需要打开后单独停止。

取消不会回滚文件改动或已完成的命令。接受成果或继续工作前，请检查[当前 diff 和命令结果](workspace-tools.md)。项目路由保证任务指向正确项目，但本身不是文件系统沙箱；执行仍使用对应的[权限模式](../reference/permissions.md)。

## 删除具名 Agent

删除会将 Agent 从列表和频道中移除，删除它的私聊与身份记忆，并撤销凭据。有任务历史也可以删除。由它负责、协调或正在执行的未结束任务会被取消；它的对话和受它管理的执行会话都会停止，包括没有关联任务的会话。

共享频道消息与已完成任务的历史归属会保留。普通项目会话的历史和文件改动仍然可用；删除不会撤销已完成的命令。

仍由该 Agent 托管的会话（包括暂停中的会话）会移入**设置 → 归档 → Agent 归档**，不再出现在工作区导航、未读列表或普通归档中。你可以将它们恢复为独立会话。已经由你接管或解除托管的会话保持原状。旧版本删除 Agent 后遗留的托管会话也会补归入这个分区。

## 保持工作可执行

房间记忆在房间内共享，身份记忆属于具名 Agent。Agent 可以在持续工作中使用这些记忆和已保存安排。定时执行要求主机处于运行状态；设备休眠或关机时，无法按时完成任务。

普通对话中的临时委派见[子代理](subagents.md)。消息、归档和分叉操作见[会话](conversations.md)。
