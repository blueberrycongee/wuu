# 技能

技能是用 Markdown 编写的可复用工作流程，适合代码审查、桌面问题诊断、发布检查等重复任务。它给 agent 一套针对任务的步骤，但不保证结果正确，也不授予额外权限。

## 查找与使用

在桌面输入框输入 `/skills`，打开技能目录。你可以搜索发现的技能、查看源码，并对允许用户调用的技能选择 **Try now**。技能也会出现在斜杠菜单中，名称后可以附带参数：

```text
/release-check 2026.9.1
```

Wuu 引擎会向模型提供技能名称和描述。任务匹配时，模型可以通过 `load_skill` 读取完整流程。缺少描述或设置了 `disable-model-invocation: true` 的技能，不会进入自动选择目录。`user-invocable` 控制是否提供给用户直接调用。

技能是否可用取决于工作区、发现来源和当前工具集。所需工具不可用的技能可能被过滤。安装或修改后请刷新目录；如果出现的版本不对，检查它的来源路径。

## 使用前检查流程

使用第三方技能前，应阅读正文和配套脚本。正常的 `load_skill` 路径只替换参数并加载指令，不会在加载时执行内联 shell 表达式或代码块。但指令仍可能要求 agent 后续运行命令或访问网络，这些操作受会话工具和权限边界约束。

`AGENTS.md` 等项目指令会在适用范围内持续生效；技能按具体流程加载；[记忆](memory.md)则保存值得跨任务保留的信息。

## 创建或安装

需要与贡献者共享的技能放在项目中，跨项目复用的个人技能放在用户技能目录。[编写指南](skill-authoring.md)介绍发现顺序、元数据、参数和检查方法。

```bash
wuu skills lint path/to/skill
wuu skills lint --json path/to/skills-root
```

Lint 检查结构和元数据能否加载。除此之外，还应使用低风险任务验证流程实际表现。
