# 主题与设置

在**设置 → 外观**中选择主题、调整阅读偏好。已启用插件可以添加主题和自己的设置，不需要替换内置设置界面。

## 选择主题

**跟随系统**使用操作系统的外观，**浅色**和**深色**固定使用对应外观。**内容主题**选择当前外观下已启用插件提供的主题，浅色和深色分别保存。选择**默认**即可移除当前模式的插件主题覆盖。

禁用或移除插件也会移除它提供的主题。如果主题影响使用，可以切回内置主题，或在插件管理中禁用它。

## 外壳皮肤

外壳皮肤装饰 ribbon 和窗口四周。在**设置 → 外观 → 外壳皮肤**中选择预览即可立即应用，圆角矩形内的内容区保持自己的背景，独立于皮肤。

插件提供成套的浅色和深色方案。禁用或移除皮肤插件会恢复默认外壳；保留的选择会在插件再次可用时恢复。安全模式也会移除插件皮肤。外壳皮肤示例（`examples/plugins/shell-skins`）提供两套完整皮肤，无需运行时或桌面模块。

## 使用背景图片

桌面端在外观中点击**背景图片 → 选择图片**，导入本地 PNG、JPEG 或 WebP，文件最大 20 MB、像素最多 6400 万。Wuu 会在当前桌面应用配置中保存一份最长边不超过 2048 像素的副本，之后可以移动或删除原文件。图片不会上传，也不会同步到其他设备。动态图片仅使用静态帧。

图片只装饰外壳和 ribbon，包括展开的 ribbon。会话、设置和工作区内容保留各自底色。导入后自动选择**我的图片**，切换到其他皮肤会保留已保存的图片。Wuu 自动居中铺满图片，使用高斯模糊柔化细节、保留色彩，并适配深浅外壳文字的对比度。这是统一的产品处理，不提供效果、浓度或位置调节。修改会应用到已打开的桌面窗口。点击**移除**会删除保存的副本；导入或保存失败时保留原来的图片。已保存的图片同样采用这套处理。

## 调整文字与动效

UI 字号统一控制界面和会话正文。代码字号单独设置，因此可以放大消息，而不必按相同比例放大代码块和编辑器。升级会保留已有的有效偏好。

界面、正文和代码可分别选择字体。正文默认**与界面字体相同**，用于消息、草稿与 Markdown 预览，字号跟随 UI 偏好。行内代码随所在正文缩放，代码块、Diff 和编辑器使用独立代码字号。**恢复默认字体**会恢复三种字体选择，保留字号。

macOS 的**字体平滑**默认使用系统渲染，让常规文字的笔画更饱满；选择**灰度平滑**可获得较轻的效果。也可以设置减少动效。字体需要安装在本机，不可用时会使用后备字体。

## 控制提交署名

在**设置 → 运行 → Git**中，**Agent 提交署名**控制 Wuu 是否为它创建的提交追加 `wuu-agent[bot]` 共同作者，原作者和其他共同作者会保留。会话运行时也可以保存此设置；该会话会继续使用原设置，等当前轮次和后台任务结束后，在下次运行时应用新设置。

## 修改插件设置

打开插件设置页，或在**技能与插件**中打开详情。Wuu 可以为声明的布尔、文本、数字和枚举字段生成控件；插件也可以提供自定义设置内容。

布尔和枚举字段在改变时保存，文本和数字字段在失去焦点时保存。离开页面前确认保存结果；失败时可以重试。

每个声明字段会标明用户或工作区作用域，以及立即生效还是重启后生效。工作区值只影响对应工作区。默认情况下，禁用、更新和移除会保留设置与插件存储；移除包不等于擦除数据。

## 主题或设置未出现

检查插件是否启用、是否声明了预期的主题或设置，以及详情页是否报告信任、兼容性或激活问题。设置标明需要重启时，按提示操作。恢复命令见 [Wuu 插件](plugins.md#恢复与排查)。

主题和设置的声明方式见[编写参考](plugin-authoring.md#声明式贡献)。自动生成的[主题界面矩阵](theme-surface-matrix.md)列出了主题变量与界面区域的对应关系。
