# 使用插件主题与设置

启用的插件可以贡献主题和设置项。本页说明用户怎样选择、恢复和管理这些贡献；
开发者需要声明字段时，查看[插件开发参考](plugin-authoring.md#声明式贡献)。

## 选择或恢复主题

打开**设置 → 外观**。除了**跟随系统**、**浅色**和**深色**，启用的插件主题也会
出现在主题列表中。选择后立即应用，不需要重启。

要停止使用插件主题，选择任意内置主题：

- **跟随系统**：按系统外观切换；
- **浅色**或**深色**：固定使用对应内置主题。

切回内置主题会移除插件覆盖的 Token。禁用或移除提供该主题的插件时，主题贡献也会消失；
Wuu 不允许外观插件隐藏设置、插件管理或恢复入口。

## 调整阅读字号和界面缩放

桌面端默认使用 14.5px UI 字号和缩小一档的界面比例，已有的字号偏好会保留。
可在设置中调整 UI 字号，代码字号独立设置。使用「视图」菜单的放大、缩小或实际大小
调整整个界面的比例，应用会在重新加载后记住这个选择。这只是起始组合，并非固定要求。

## 管理插件设置

插件声明的布尔、文本、数字和枚举设置会由 Wuu 渲染，不需要插件自己实现表单。安装后，
可以从以下入口找到：

- **设置**侧栏中插件贡献的设置页；
- **技能与插件**中对应插件的详情。

布尔和枚举修改会直接保存；文本和数字通常在离开输入框时保存。每项会显示默认值、作用域
以及是立即生效还是需要重启。保存失败时使用界面中的重试操作。

设置分为用户级和工作区级。工作区设置只影响当前工作区。禁用、升级或移除插件时，Wuu
默认保留设置和 Storage，方便以后重新启用；当前不会自动清除这些数据。

## 找不到主题或设置

依次检查：

1. 插件是否已安装并启用；
2. 插件的来源身份是否未变；
3. manifest 是否真的声明了主题或设置；
4. 设置项是否要求重启后生效；
5. **技能与插件**中的插件诊断是否报告 manifest 或激活错误。

需要禁用、检查或移除插件时，查看 [Wuu Plugin 的恢复路径](plugins.md#恢复与故障处理)。
