# 主题与设置

在**设置 → 外观**中选择主题、调整阅读偏好。已启用插件可以添加主题和自己的设置，不需要替换内置设置界面。

## 选择主题

**跟随系统**使用操作系统的外观，**浅色**和**深色**固定使用对应外观。插件主题与这些选项一起显示，选择后立即生效。切回内置选项即可移除插件主题覆盖。

禁用或移除插件也会移除它提供的主题。如果主题影响使用，可以切回内置主题，或在插件管理中禁用它。

## 使用背景图片

桌面端在外观中点击**背景图片 → 选择图片**，导入本地 PNG、JPEG 或 WebP，文件最大 20 MB、像素最多 6400 万。Wuu 会在当前桌面应用配置中保存一份最长边不超过 2048 像素的副本，之后可以移动或删除原文件。图片不会上传，也不会同步到其他设备。动态图片仅使用静态帧。

背景以居中裁切的方式连续覆盖侧栏、会话、设置和工作区画布。菜单、输入框、编辑器和预览保留各自底色，保证可读性。可选择原图、抖色、半色调、ASCII 字符或扫描线，并在 5% 至 30% 之间调整图片浓度。修改会应用到已打开的桌面窗口。点击**移除**会删除保存的副本；导入或保存失败时保留原来的背景。

## 调整文字与动效

UI 字号统一控制界面和会话正文。代码字号单独设置，因此可以放大消息，而不必按相同比例放大代码块和编辑器。升级会保留已有的有效偏好。

外观设置还支持选择 UI 字体、代码字体和减少动效。指定字体需要已经安装在本机，否则界面会使用后备字体。

## 控制提交署名

在**设置 → 常规 → 行为**中，**Agent 提交署名**控制 Wuu 是否为它创建的提交追加 `wuu-agent[bot]` 共同作者，原作者和其他共同作者会保留。会话运行时也可以保存此设置；该会话会继续使用原设置，等当前轮次和后台任务结束后，在下次运行时应用新设置。

## 修改插件设置

打开插件设置页，或在**技能与插件**中打开详情。Wuu 可以为声明的布尔、文本、数字和枚举字段生成控件；插件也可以提供自定义设置内容。

布尔和枚举字段在改变时保存，文本和数字字段在失去焦点时保存。离开页面前确认保存结果；失败时可以重试。

每个声明字段会标明用户或工作区作用域，以及立即生效还是重启后生效。工作区值只影响对应工作区。默认情况下，禁用、更新和移除会保留设置与插件存储；移除包不等于擦除数据。

## 主题或设置未出现

检查插件是否启用、是否声明了预期的主题或设置，以及详情页是否报告信任、兼容性或激活问题。设置标明需要重启时，按提示操作。恢复命令见 [Wuu 插件](plugins.md#恢复与排查)。

主题和设置的声明方式见[编写参考](plugin-authoring.md#声明式贡献)。自动生成的[主题界面矩阵](theme-surface-matrix.md)列出了主题变量与界面区域的对应关系。
