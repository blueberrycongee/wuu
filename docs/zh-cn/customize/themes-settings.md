# 主题与设置

在**设置 → 外观**中选择主题、调整阅读偏好。已启用插件可以添加主题和自己的设置，不需要替换内置设置界面。

## 选择主题

**跟随系统**使用操作系统的外观，**浅色**和**深色**固定使用对应外观。**配色方案**提供**默认**、**Linear**、**Codex**、**Absolutely**、**GitHub**、**Notion**、**One**，以及已启用插件提供的主题。菜单选项直接预览背景、文字和强调色，上方浅色与深色模式的预览也会反映各自保存的配色。配色统一调整会话背景、用户消息底色、正文、输入框、侧栏悬停与选中态，以及焦点强调色，助手回复保留开放式排版。

选择后立即生效，浅色和深色分别保存，跟随系统切换时也会恢复对应选择。选择**默认**可恢复当前模式的中性色，不会改变另一模式的配色或外壳皮肤。

禁用或移除插件也会移除它提供的主题。如果主题影响使用，可以切回内置主题，或在插件管理中禁用它。

## 外壳皮肤

外壳皮肤决定窗口四周和 ribbon 的样式；选择**画布摆放**的皮肤还会把图片铺在主工作区画布之下。皮肤不改变内容颜色和布局：文字、强调色和控件跟随**配色方案**，会话、设置和插件页面保持原有结构。在**设置 → 外观 → 外壳皮肤**中选择即可立即应用。

默认的 frame 摆放下，圆角工作区保持自己的内容背景，独立于皮肤。canvas 摆放下，空对话主页直接露出图片，对话盖在一层半透遮罩下，设置、Skills 和插件页面保持不透明，除非某个插件视图另行声明。输入框、卡片等浮动面板在图片上呈现磨砂质感。canvas 皮肤还可以把图片渲染成圆点或方形像素组成的网格，每格一种颜色。开启**减弱透明度**时画布保持不透明。

插件提供成套的浅色和深色方案。禁用或移除皮肤插件会恢复默认外壳；保留的选择会在插件再次可用时恢复。安全模式也会移除插件皮肤。外壳皮肤示例（`examples/plugins/shell-skins`）提供两套 frame 摆放的完整皮肤，无需运行时或桌面模块；`examples/plugins/deep-field` 演示把你自己的图片以像素网格铺入画布，同样无需代码。

## 使用背景图片

你的图片是所选皮肤的图片。桌面端选中能显示图片的皮肤时，外观中的外壳皮肤下方会出现**背景图片**：**默认**皮肤总会显示，插件皮肤需声明接受图片。点击**背景图片 → 选择图片**，导入本地 PNG、JPEG 或 WebP，文件最大 20 MB、像素最多 6400 万。Wuu 会在当前桌面应用配置中保存一份最长边不超过 2048 像素的副本，之后可以移动或删除原文件。图片不会上传，也不会同步到其他设备。动态图片仅使用静态帧。

**默认**皮肤把图片显示在外壳和 ribbon 上，会话、设置和工作区内容保留各自底色。此时 Wuu 自动居中铺满图片，使用高斯模糊柔化细节、保留色彩，并适配深浅外壳文字的对比度。接受图片的 canvas 皮肤按自己的样式（例如像素网格）把图片清晰地铺在主画布之下，并限制亮度，让上面的内容保持清晰。图片固定的皮肤不提供此项；已保存的图片会留给能显示它的皮肤。这些都是统一的产品处理，不提供效果、浓度或位置调节。修改会应用到已打开的桌面窗口。点击**移除**会删除保存的副本；导入或保存失败时保留原来的图片。已保存的图片同样采用这套处理。

## 调整文字与动效

UI 字号统一控制界面和会话正文。代码字号单独设置，因此可以放大消息，而不必按相同比例放大代码块和编辑器。升级会保留已有的有效偏好。

字体只选两次：**界面字体**用于界面、消息、草稿与 Markdown 预览，**代码字体**用于代码块、Diff 和终端。行内代码随所在正文缩放，代码块、Diff 和编辑器使用独立代码字号。**恢复默认字体**会恢复两种字体选择，保留字号。

macOS 的**字体平滑**默认使用系统渲染，让常规文字的笔画更饱满；选择**灰度平滑**可获得较轻的效果。也可以设置减少动效。字体需要安装在本机，不可用时会使用后备字体。

## 控制提交署名

在**设置 → 常规 → Git**中，**Agent 提交署名**控制 Wuu 是否为它创建的提交追加 `wuu-agent[bot]` 共同作者，原作者和其他共同作者会保留。会话运行时也可以保存此设置；该会话会继续使用原设置，等当前轮次和后台任务结束后，在下次运行时应用新设置。

## 修改插件设置

打开插件设置页，或在**技能与插件**中打开详情。Wuu 可以为声明的布尔、文本、数字和枚举字段生成控件；插件也可以提供自定义设置内容。

布尔和枚举字段在改变时保存，文本和数字字段在失去焦点时保存。离开页面前确认保存结果；失败时可以重试。

每个声明字段会标明用户或工作区作用域，以及立即生效还是重启后生效。工作区值只影响对应工作区。默认情况下，禁用、更新和移除会保留设置与插件存储；移除包不等于擦除数据。

## 主题或设置未出现

检查插件是否启用、是否声明了预期的主题或设置，以及详情页是否报告信任、兼容性或激活问题。设置标明需要重启时，按提示操作。恢复命令见 [Wuu 插件](plugins.md#恢复与排查)。

主题和设置的声明方式见[编写参考](plugin-authoring.md#声明式贡献)。自动生成的[主题界面矩阵](theme-surface-matrix.md)列出了主题变量与界面区域的对应关系。
