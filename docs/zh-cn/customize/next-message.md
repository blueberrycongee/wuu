# 下一句建议

可选的 **Next message（下一句建议）** 插件会在正常完成回复后，预测你可能输入的一句话。插件内置但默认关闭。在 **设置 → 扩展** 中启用，再打开插件设置选择已配置的模型别名。

建议以灰字显示在空输入框内，即使输入框没有焦点也会生成和显示。输入框获得焦点后，**Tab** 只把建议填入草稿，不发送；发送前可以继续编辑。**Escape** 取消建议。输入文字、切换会话、开始新轮次、关闭插件都会取消待处理请求，过期结果不会写入草稿。斜杠命令和菜单保留按键优先级。没有建议时，Tab 保持原有焦点导航行为。

## 模型、数据和费用

模型别名留空时，每次预测都会读取工作区当前配置的主模型；之后切换主模型，建议也会跟着切换。它不会自动选择专用低价模型。填写已配置的模型别名后，切换主模型不会改变这里的选择；别名不可用时不显示建议，也不会悄悄回退到其他模型。

每个符合条件的轮次最多尝试一次。请求限时 15 秒，含预测提示词和 JSON 编码的 UTF-8 输入不超过 8 KiB。支持的提供商会收到 128 个输出 token 的上限；Codex 不支持这个参数，因此其输出和费用可能更高。显示的建议最多 100 个 Unicode 字符，优先一句话，最多两句短句。超过输入预算时先舍弃较早的完整轮次；最新一轮仍过大则跳过，不截断消息。取消后仍可能产生提供商费用。请求成功也可以没有建议。

会把最近已完成轮次中可见的用户文字和最终助手回复发送给所选提供商，且包含最新一轮。带附件的源轮次只发送图片、文件数量作为提示，不发送附件字节、名称或路径。不包含未提交草稿、工具输出和推理。插件不创建私有会话、不调用工具，也不读写笔记本。仅持久保存模型别名，不保存源对话文字；宿主和提供商正常的用量记录仍适用。

## 触发条件

插件启用期间，必须观察到同一轮次的实时开始和正常完成。恢复旧会话，或者在回复完成后才启用、重载插件，都不触发预测。失败、中断、内部、生成式和内容不完整的源轮次会跳过。纯附件轮次没有可用于预测的用户文字，也会跳过。输入框必须严格为空，且没有附件、排队消息或待处理输入。

支持已注册工作区、无项目会话、分屏和侧会话。侧会话只读取自身历史，不借用所属主会话的对话内容。工作区根目录、会话和源轮次标识必须一致。输入变化会沿原始 promise 取消运行时及模型请求；失去或重新获得焦点不会重启预测。近期去重标识只保存在内存，作用范围是当前插件运行代次。

插件读取宿主的可见会话投影，不读取物理审计记录。有限的上下文仍可能遗漏较早的内容，建议也可能不准确。合成测试验证交互与取消链路，不代表真实模型的建议质量。
