# 下一句建议

可选的 **Next message（下一句建议）** 插件会在正常完成回复后，预测你可能输入的一句话。插件内置但默认关闭。在 **设置 → 扩展** 中启用，再打开插件设置选择并保存模型。

预测提示词优先引导模型使用你的语言和表达习惯，预测推进当前目标的后续操作、追问、纠正或回答。它要求省略客套和没有实际内容的确认，并在没有明确后续意图时不提供建议。

建议以灰字显示在空输入框内，即使输入框没有焦点也会生成和显示。输入框获得焦点后，**Tab** 只把建议填入草稿，不发送；发送前可以继续编辑。清空采纳的草稿或撤销插入后，同一条建议会重新显示，可再次按 Tab 采纳，不会重复请求模型。**Escape** 取消建议。切换 tab、会话或工作区不会中断已开始的预测；切回来时，如果输入框仍符合显示条件，会显示该会话的结果。输入文字、打开菜单或附加文件会暂时隐藏建议。开始新轮次或关闭插件会取消旧预测，过期结果不会写入草稿。斜杠命令和菜单保留按键优先级。没有建议时，Tab 保持原有焦点导航行为。

## 模型、数据和费用

生成建议前，必须从已配置的提供商中选择并保存一个模型。选定模型后可选择它支持的推理档位；新选模型支持 `low` 时默认选 `low`，也可明确选择“模型默认”。已有的模型别名也可以选择，此时档位由别名配置决定。旧版只保存模型的设置继续优先使用受支持的 `low` 档位，重新保存后会记录界面上选定的档位。插件不会自动使用工作区默认模型或当前会话模型。所选模型、别名或明确指定的档位不可用时不显示建议，也不会悄悄回退到其他模型或档位。较高档位可能超过 30 秒时限。

每个符合条件的轮次最多尝试一次。请求限时 30 秒，含预测提示词和 JSON 编码的 UTF-8 输入不超过 8 KiB。支持的提供商会收到 128 个输出 token 的上限；Codex 不支持这个参数，因此其输出和费用可能更高。显示的建议最多 100 个 Unicode 字符，优先一句话，最多三句短句。超过输入预算时先舍弃较早的完整轮次；最新一轮仍过大则跳过，不截断消息。取消后仍可能产生提供商费用。请求成功也可以没有建议。

会把最近已完成轮次中可见的用户文字和最终助手回复发送给所选提供商，且包含最新一轮。带附件的源轮次只发送图片、文件数量作为提示，不发送附件字节、名称或路径。不包含未提交草稿、工具输出和推理。插件不创建私有会话、不调用工具，也不读写笔记本。仅持久保存模型选择，不保存源对话文字；宿主和提供商正常的用量记录仍适用。

## 触发条件

插件启用期间，必须观察到同一轮次的实时开始和正常完成。回复完成时就开始预测，不要求该会话的输入框仍在屏幕上。恢复旧会话，或者在回复完成后才启用、重载插件，都不触发预测。失败、中断、内部、生成式和内容不完整的源轮次会跳过。纯附件轮次没有可用于预测的用户文字，也会跳过。显示建议时，输入框必须严格为空，且没有附件、排队消息或待处理输入。

支持已注册工作区、无项目会话、分屏和侧会话。侧会话只读取自身历史，不借用所属主会话的对话内容。工作区根目录、会话和源轮次标识必须一致。预测任务由源轮次持有；输入框的显示和取消信号不会终止模型请求。新轮次、服务器断开、设置变更或插件关闭会使旧结果失效。建议和近期去重标识只保存在当前插件运行代次的内存中。

插件读取宿主的可见会话投影，不读取物理审计记录。有限的上下文仍可能遗漏较早的内容，建议也可能不准确。合成测试验证交互与取消链路，不代表真实模型的建议质量。
