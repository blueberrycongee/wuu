# Wuu 插件

独立 [MCP 服务](mcp.md)在插件目录中管理。插件自带的 MCP 显示在插件详情页，可直接连接和登录。

需要账号授权时，在目录中打开 **Account Connectors**。服务初始为禁用状态；Notion 提供浏览器 OAuth，GitHub 和 Google Drive 则展示尚需完成的应用配置。详见[连接账号](mcp.md#连接账号)。

Wuu 插件把 agent 行为、桌面界面或其他扩展贡献打包在一起，可以包含工具、技能、Hook、MCP 服务、主题和设置。只启用你信任的代码：插件拥有运行 Wuu 的用户权限，不在 Wuu 沙箱内运行。

## 安装本地包

打开**技能与插件**，安装本地目录或 zip 包。安装即确认信任该来源并启用插件。Wuu 没有中央市场，安装器也不会直接下载 npm 包或 Git 仓库。

CLI 使用相同的信任规则：

```bash
wuu plugin install ./my-plugin
wuu plugin list
```

请使用包中声明的 ID。安装会把文件复制到 Wuu 主目录的 `plugins/` 下，默认是 `~/.wuu/plugins/`，设置 `WUU_HOME` 后位置随之改变。安装会通过所选配置服务记录来源与精确包指纹。激活仍需满足兼容性与依赖要求；无法启动时应查看诊断。

## 更新、禁用与移除

可以从目录或 zip 安装替换包，也可以使用：

```bash
wuu plugin update my-plugin ./my-plugin
```

来自同一已记录来源的更新继承信任，并保留启用或禁用选择。来源改变，或旧授权尚未记录来源时，更新保持待确认，原版本继续有效。可在详情页或通过 `wuu plugin approve my-plugin` 确认来源变化。仅版本或内容指纹变化不要求再次批准。直接复制文件到安装目录不属于更新流程。

本地包的来源是解析符号链接后的目录或 zip 绝对路径。在同一路径替换 zip 属于同源更新；改用其他路径需要确认。

禁用提交成功后，会停止所有仍被引用的运行时 generation 中该插件的行为，但保留文件：取消原生执行，阻止所属 MCP 服务重连，并移除后续旧式 hook 和请求转换。已经运行的旧式 hook 保留调用方生命周期；已完成的效果和会话历史不变。这与同 ID 更新不同，更新允许活动工作使用原代完成。不再需要时可以移除包：

```bash
wuu plugin disable my-plugin
wuu plugin enable my-plugin
wuu plugin remove my-plugin
```

默认会保留设置和插件存储。移除不会擦除插件创建的全部数据，也不会撤销已完成操作。

## 恢复与排查

默认组合中的可选插件即使在初始化、准备或激活阶段失败，也不会阻止 CLI 禁用或移除操作。失败的运行时保持不可用，可通过 `wuu plugin describe` 查看诊断。`wuu plugin list --json` 只列出已发现的包，不启动运行时，也不表示实时激活状态。显式组合模块和所选服务绑定仍是必需契约；恢复写入不会用默认值覆盖无效配置。

如果操作报告变更已提交、但运行时激活失败，设置或包变更已经生效。重试前应检查新清单中的失败诊断；旧运行时不会自动恢复。参见 [generation 生命周期](plugin-system.md#运行时-generation)。

详情页区分待信任、已禁用、启动中、运行中、失败和待更新等状态。请查看实际错误，不要把所有功能缺失都当作安装失败。缺少依赖或其他包不兼容，也可能阻止激活。

桌面代码渲染失败时，Wuu 会尽可能隔离出错的贡献，并保留插件管理和默认界面恢复入口。禁用可疑插件后，使用默认界面重试。插件自身界面损坏时，可以使用 CLI 操作。安全模式用于从插件相关启动故障中恢复，并不代表重新启用该包就安全。

## 插件能提供什么

agent 运行时可以注册工具、补充上下文、观察支持的生命周期事件，以及提供或调用有版本的服务。桌面模块可以添加视图、固定插入点、语义渲染替换、会话卡片和样式。声明式主题和设置不需要桌面模块，见[主题与设置](themes-settings.md)。

内置功能也使用这些机制。具体用法见[子代理](../desktop/subagents.md)、[自动化](../automation/scheduled-tasks.md)和[记忆](memory.md)。Peers 插件让 agent 联系同一工作区已有的会话，与创建子代理是不同功能。

## OpenDesign 预设

可选的 **OpenDesign Presets** 插件提供一个 `opendesign` 技能，用于选择设计系统、
从作品模板开始制作，或在网站、仪表盘、移动界面和 HTML 演示文稿中应用设计规则。
例如：“用 OpenDesign 做一个 Linear 风格的仪表盘。”技能会检索本地目录，按需
读取选中的资源。

在**技能与插件**中安装构建后的 `opendesign-presets` 目录或 zip，也可以使用
`wuu plugin install`。从源码构建请参见[打包说明](../../../plugins/opendesign-presets/README.md)。
安装包固定上游提交，保留署名和许可证，使用时无需安装 OpenDesign。
禁用 `opendesign-presets` 后，其技能会从可用目录中移除。

此包提供预设和适配 Wuu 的工作流。OpenDesign 的画布、元素批注、直接编辑和媒体
服务属于独立的应用能力。媒体条目提供提示词配方，实际生成仍需要可用工具。
模板可能引用可选依赖或远程资源；技能会把上游的预览和输出约定适配到当前项目
及 Wuu 工具。

## 监控后台事件

内置 Monitor 插件会运行 shell 脚本，让 agent 同时继续工作。例如，可以让它盯住 CI，
某项检查失败时立即报告，全部通过后结束。脚本应只输出相关变化；每批输出都可能唤醒
会话或进入当前回合。监控事件是观察数据，不会替你回答 agent 正在等待的问题。

展开输入框上方的**监控**，可以查看描述、行数、任务 ID、状态、命令、截止时间和输出。
agent 空闲时仍会显示运行数量。展开任务可跟随输出或停止整个进程树；手动停止会明确
告诉 agent，除非你要求，否则不要重新启动。私有子会话完成后，它启动的监控会交给父会话。

`monitor` 接收 `command`、`description`，以及可选的 `timeout_ms`（默认及上限均为
10 小时）和 `persistent`。持续监控没有截止时间，直到手动停止、会话归档或删除、
插件运行时结束。`monitor_tasks` 可以列出、读取或停止当前会话的监控。

标准输出和标准错误会合并，忽略空行，退出时发送末尾不完整的行，每 200 毫秒合并一次。
事件最多突发发送 10 批，每两秒恢复一个额度；过量批次会计数，持续过量 30 秒会停止脚本。
事件中每行缩短至 500 字节，每批缩短至 3,000 字节，输出查看器使用保留的进程日志。
管道应启用行缓冲，脚本应自行处理暂时的网络错误。

shell 执行目前需要本地工作区，并遵循其 shell 权限和沙箱策略。禁用插件或运行时退役会
停止所属进程。重启后，原先运行中的记录显示为已中断，并保留最近的输出，不会自动
重启脚本。最多保留 64 条任务记录。

## 开发插件

从 [agent 快速开始](plugin-quickstart.md)或[桌面快速开始](desktop-plugin-quickstart.md)入手。本地开发与安装可分发包是不同流程。[编写参考](plugin-authoring.md)介绍清单、开发命令、版本要求和包关系。

Wuu 不审计、认证或托管第三方扩展。运行陌生代码前，请确认它与当前 Wuu 构建兼容，并阅读[安全模型](../reference/security-model.md)。
