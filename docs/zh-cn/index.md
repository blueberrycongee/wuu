# wuu 文档

wuu 让你和 AI Agent 一起处理本地项目。Agent 可以读写文件、运行命令，并在保存的对话里继续工作。你接上模型，再检查它的工作结果。

第一次使用，从[快速开始](getting-started/index.md)入手：安装桌面应用、连接模型，试着完成一个小任务。

选择项目、继续之前的工作，可以看[工作区](desktop/workspaces.md)和[对话](desktop/conversations.md)。想检查 Agent 做了什么，可以打开[文件、改动与终端](desktop/workspace-tools.md)。需要多个 Agent 一起做事时，再看[群聊协作](desktop/collaboration.md)。

使用敏感资料前，请先读[权限](reference/permissions.md)和[安全说明](reference/security-model.md)，了解 wuu 能访问哪些文件，以及数据会发往哪里。

有需要时，再看[扩展方式](customize/index.md)、[命令行自动化](automation/exec.md)或[故障排查](help/troubleshooting.md)。
