## 可确认的外部依据

Rob Janoff 的官方 Apple Logo 创作回顾：

https://robjanoff.com/applelogo/

已读取的正文描述他观察真实苹果的横截面，随后完成设计。这段回顾没有建立“按斐波那契圆构造”的证据。它足以要求对黄金比例起源说保持谨慎，但不能把“没有提到”改写成其逐字否认。

## 数学事实与设计推测分开

- 黄金比例 φ = (1 + √5) / 2，约为 1.618；这是数学定义，不是美感保证。
- 黄金角的较小角为 360° / φ²，约为 137.508°，适用于某些分布与构图问题，不是任意 UI 弧线都应满足的角度。
- 相邻斐波那契数之比趋近 φ；从有限圆形尺寸中挑出近似匹配，并不能证明设计者使用了该构造。
- 某比例在多个位置近似出现仍可能来自选择性测量、可调尺度和事后选择。没有原始设计文档就不推断设计意图。

## 视觉解释的限制

亮度对比、空间上下文、形状、阴影解释和显示条件都可能影响视觉感受。不要把一个简化的生理机制扩展成所有错觉的唯一原因；本 skill 只要求基于实际输出做对照验证。
