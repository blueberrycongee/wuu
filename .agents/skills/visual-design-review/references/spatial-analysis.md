# 多尺度重量、阴影与留白

这些方法产生可解释的感知代理，而不是经过验证的人类注意力预测。项目适配器负责执行像素处理；本包的评分器只接收最终误差。保留算法、库版本和中间图，避免每次任务重新发明权重。

## 对比度场与高斯模糊

先按测量协议进行颜色管理与透明合成。对于语义区域的每个像素，建立局部背景参考 `B(p)` 与线性亮度 `Y(p)`，取 `C(p)=abs(Y(p)-B(p))`。背景参考优先来自配对背景或确认的均匀区域；背景估计不可靠时不能声称精确分离。不得直接把深色主题整片底色当作内容重量。

对完整带上下文的场做 `D_s=G_sigma*C`，再裁到目标 ROI。高斯核归一化；记录边界扩展方法，预留至少约 `3*sigma` 的真实上下文，超出截图的区域标记被截断。固定边界算法并验证总量变化，防止裁剪或零填充制造虚假的边缘偏轻。

建议以容器短边 `L` 的 `0.01L / 0.04L / 0.12L` 作为小、中、大尺度的**实验起点**，不是通用推荐值。先统一逻辑采样分辨率，记录降采样与像素倍率；小区域的 sigma 下限和所有尺度系数写入场景版本。分别输出各尺度图，不只留一张平均热力图。

| 尺度 | 主要用途 | 不应得出的结论 |
| --- | --- | --- |
| 控件内部 | 可见笔画位置、图标与文字组合 | 单靠模糊能给出精确基线 |
| 语义分组 | 一组操作或列表行的密度分布 | 同组必须每项一样重 |
| 面板构图 | 重量集中区、空白与密度梯度 | 全屏质心必须在正中央 |

**对称归一化卷积在完整平面上保留总量和一阶矩。** 所以不能只计算模糊前后的质心，再把它们当作新的多尺度证据；观察各尺度的分区重量、局部密度、空白连通区域与梯度。裁剪后质心变化还可能来自边界损失。

每个场景预先指定区域和目标重量占比区间 `[a_i,b_i]`。可用 `m_i=sum(D_s in region_i)/sum(D_s in ROI)` 与区间的距离描述偏差，区域必须组成明确的不重叠分区。没有非零内容重量则不可测，不给“完美平衡”分。多尺度和多个相近指标须共享固定权重，避免对同一个偏差重复扣分。

亮度模型可能漏掉等亮异色元素，语义显著性也不在模型中。可选色差模型必须另行声明颜色空间、公式和版本；不能临时引入一个“饱和度系数”来修正不喜欢的结果。

## 光学对齐

同时保留布局锚点、可见轮廓中心和对比度质心。比较同一角色的元素或指定参照：图标与文字、按钮内图形、同行的可见边缘。字体下伸部、不对称图标和已校正资源都可能造成合理的差异。

选择一个主要误差避免重复计分，例如可见中心相对已确认目标的横向偏移除以容器宽度；几何框偏差作为辅助证据。多个元素按场景固定权重聚合，额外报告最大局部偏差，不能用平均值掩盖严重个例。未经校准的质心只产生候选，不直接生成相反方向的 CSS 偏移。

## 阴影与其他效果

使用同状态原样图 `I_on` 和仅去除目标阴影的图 `I_off`。在线性颜色空间内计算差分，例如亮度绝对差 `S(p)=abs(Y_on(p)-Y_off(p))`。同时保留有符号差分，以区分暗影和亮光；如果颜色效果重要，亮度差不够，需声明色差提取器。

可报告：差分总量、阈值敏感的可见覆盖范围、各方向贡献、差分质心偏移，以及完整画面分区重量在两种状态下的变化。总量比值需要明确分母；分母接近零时不可测，不能靠任意 epsilon 得到巨大的分数。

阴影的差分质心不是控件的光学中心。底部阴影较重可能是正确的高度暗示，不要求它对称或为零。与同类组件、同背景和同状态的效果目标比较。透明叠加、遮挡和背景会改变贡献，不能把分别计算的阴影重量与主体重量简单相加当作真实合成结果。

效果项应衡量既定层级/方向是否一致、是否意外侵入相邻内容，而不是奖励移除阴影。完整画面的重量项与效果项采用不同的已声明问题；同一现象可以有两张证据图，但不能偷偷获得双倍扣分。

## 空白区域与空间占用

空白分析至少使用两种信息：语义布局占用（容器、控件、保留输入区）与低对比区域（多尺度密度低于指定阈值）。平坦按钮背景不等于未使用空间；文字行内字距也不等于面板间隙。

在指定可评估区域内，提取低密度掩膜并做连通区域/距离变换，报告空白面积占比、最大连通块、最大空圆半径或最大空矩形、到相邻内容的距离。明确 4/8 连通、阈值、ROI 和排除区域，并做阈值敏感性分析。触及截图边界的空白可能是裁剪结果，不推断完整形状。

分别分析标题到正文、组内、组间、正文到操作区。阅读区、拖放区、编辑空间和品牌留白的可接受区间由场景用途决定。对留白占比 `f` 与目标区间 `[a,b]` 可用 `max(a-f,0,f-b)` 作为归一化偏离，不预设“越满越好”。不要为了提高得分删除必要内容或塞入装饰。

## 提取器验收

实现图像适配器时，用原创合成图测试：平移导致已知方向的偏移；左右镜像反转有符号偏移；均匀缩放后归一化结果近似不变；空场不可测；对称阴影与偏置阴影可区分；禁用阴影不改变布局；边界裁剪被识别。重复采集真实渲染，验证方法对抗锯齿与字体差异的敏感性。

这些是提取器需要完成的验收，不是本包已经运行过的图片分析测试。不得以公式、合成图或分数替代实际尺寸下的视觉判断。
