# ChatGPT workspace

This optional package is not bundled with Wuu. It needs no build. From the repository root:

```sh
wuu plugin install ./plugins/chatgpt-workspace/package
wuu plugin approve chatgpt-workspace
```

It opens the ChatGPT website; sign in through the website. It provides no API tools.
See [package details and artwork attribution](package/README.md).

此插件不随 Wuu 分发。可在仓库根目录运行上述命令按需安装，无需构建。它提供 ChatGPT 网页入口，不提供 API 工具；请在网页中登录。
