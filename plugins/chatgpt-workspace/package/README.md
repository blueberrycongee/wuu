# ChatGPT workspace example

Enable this optional desktop extension to add ChatGPT to the reorderable ribbon.
It uses the existing native website surface and browser profile; sign in on the website.
Disabling the extension closes its view without deleting browser cookies.

This extension has no API tools or API credentials. A ChatGPT subscription is not an API token.
Website access is subject to the service's own login, account and browser policies.
The native view is supported in the main desktop workbench, not remote/mobile or pop-out windows.

## Artwork

The monochrome OpenAI mark reuses Wuu's existing `EngineIcons.tsx` artwork, attributed there
to Simple Icons (CC0). The mark identifies the external website; this extension is not affiliated with OpenAI.
