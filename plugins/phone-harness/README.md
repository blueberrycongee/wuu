# Phone Harness plugin

Wuu adapter for the separately installed [Phone Harness](https://github.com/ShawnPana/phone-harness) CLI, verified against version 0.3.2 (MIT). No upstream runtime code is vendored. The adapter uses the public Wuu TypeScript SDK and the upstream Python helper interface.

See the user guide in [English](../../docs/en/customize/phone-control.md) or [简体中文](../../docs/zh-cn/customize/phone-control.md) for installation and device setup.

Build with `npm --prefix plugins/phone-harness run build`. Then use `wuu plugin dev plugins/phone-harness` for directory development, or install `internal/plugin/bundled/phone-harness` as a local package. The canonical manifest and skill live in that directory; `runtime.mjs` is generated by `scripts/build-bundled-plugins.mjs`.
